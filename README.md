# 골라주개냥 (GollajuDogCat)

> 정보가 없는 게 아니라, **우리 아이에게 적용할 정보**가 부족했던 거예요.

반려동물 프로필을 기준으로 상품을 해석해 주는 B2C 종합 이커머스 서비스입니다.
이 저장소에는 Phase 1 리서치 결과(문제 정의 · 솔루션 우선순위)를 바탕으로 만든 **클릭 가능한 프로토타입**이 들어 있습니다.

## 이번 프로토타입의 범위

RICE 우선순위 1~3위를 중심으로, 커머스 기본기와 예외 케이스를 함께 담았습니다.

### 우선순위 1~3위 (핵심 구현)

| 순위 | 기능 | 프로토타입에서 확인할 것 |
| --- | --- | --- |
| 1 | **프로필** (2.1.1) | 5단계 등록 폼, 생애주기 자동 판정, 대표 반려동물 전환, 등록 직후 "먼저 확인할 것" 제시 |
| 2 | **상품 추천** (2.1.3) | 프로필 기준 맞춤 점수 정렬, 알레르기 성분 자동 제외, 추천 사유 표시 |
| 3 | **성분 분석** (2.1.5) | 수치 해석 · 툴팁 · 기준 이탈 뱃지, 관심사별 성분 우선 정렬, 적정 급여량 계산, A/B 비교 |

### 커머스 기본기

카테고리 · 필터/정렬 · 검색(자연어 포함) · 장바구니 · 주문/결제 · 주문 내역 · MY

### 최소 구현 (4~5위)

- **리뷰 분석 & 필터** (2.1.2): "우리 아이와 비슷한 조건" 필터, AI 요약 + 반응별 통계, 구매횟수·사용기간 표시
- **구입 이후 체크** (2.1.4): 7·14·30일 체크 알림, 상품 종류별 확인 항목, 관찰 중/계속/중단 3지선다

### 예외 케이스

프로필과 맞는 상품이 없는 경우 · 맞는 리뷰가 없는 경우 · 리뷰가 없는 신상품 ·
검색 결과 없음 · 빈 장바구니 · 주문 내역 없음 · 콜드 스타트 유저 · 반려동물 미등록

## 맞춤 점수는 어떻게 계산되나요

핵심 페인포인트가 "내 반려동물을 기준으로 정보를 해석하기 어렵다"이므로,
프로토타입에서도 점수를 임의로 넣지 않고 실제 계산식으로 만들었습니다. (`scoreProduct`)

기본 46점에서 시작해 아래 항목을 더하고 뺍니다.

| 항목 | 가감 |
| --- | --- |
| 생애주기 일치 | +10 / 불일치 −10 |
| 등록한 알레르기 성분 포함 | **−38** (추천 목록에서도 제외) |
| 알레르기 성분 미포함 | +6 |
| 건강 관심사 일치 | 항목당 +7 (최대 2개) |
| 성분 평가 | 양호 항목당 +1.6 / 기준 이탈 항목당 −5 |
| 리뷰 평점 | (평점 − 4.3) × 10 |
| 리뷰 없음 | −4 |
| 신장 관심사 + 인 함량 | 0.6% 이하 +7 / 1.0% 이상 −10 |

최종 20~97점으로 보정합니다. 같은 상품이라도 보는 아이가 바뀌면 점수와 근거 문구가 함께 바뀝니다.

예) 데일리 치킨&라이스 → 보리(닭고기 알레르기) **20점**, 관절 플러스 시니어 → 보리(어덜트) **20점**,
연어 그레인프리 → 보리 **85점** / 신장 케어 레시피 → 나비(신장) **83점**, 캣 연어&황태(인 1.1%) → 나비 **47점**

급여량 가이드도 실제 계산입니다. 체중 기반 RER에 생애주기·중성화·체중관리 계수를 곱해
하루 필요 칼로리를 구하고, 상품의 100g당 열량으로 나눠 하루 급여량(g)을 냅니다.

## 알아두어야 할 점

- 모든 데이터는 목(mock)입니다. 서버 호출이 없고, 상태는 브라우저 `localStorage`에만 저장됩니다.
- 상품 16종, 리뷰 40여 건은 기능을 보여주기 위해 구성한 가상 데이터입니다. 실제 제품·브랜드가 아닙니다.
- 성분 해석 문구는 일반적인 영양 가이드라인을 참고한 예시이며, 의학적 조언이 아닙니다.
- 자연어 검색은 키워드 규칙 기반 간이 파서입니다. 실제 서비스에서는 AI 파트가 담당할 영역입니다.
- 사진 업로드, 실제 결제, 배송 추적, 교환·반품은 범위 밖입니다.
- 체크 알림은 구매 후 7·14·30일에 발송되므로, 알림 화면의 `7일 경과시키기` 버튼으로 시연합니다.
