# 골라주개냥 (GollajuDogCat)

> 정보가 없는 게 아니라, **우리 아이에게 적용할 정보**가 부족했던 거예요.

반려동물 프로필을 기준으로 상품을 해석해 주는 B2C 종합 이커머스 서비스(iOS 앱)입니다.
이 저장소에는 **IA v0.3**을 기준으로 만든 클릭 가능한 프로토타입이 들어 있습니다.

## 적합도 점수는 실제 계산식입니다

핵심 페인포인트가 "내 반려동물을 기준으로 정보를 해석하기 어렵다"이므로, 점수를 하드코딩하지 않고
프로필·성분·리뷰를 조합해 계산합니다. (`fitScore`)

기본 46점에서 시작해 아래 항목을 더하고 뺍니다.

| 항목 | 가감 |
| --- | --- |
| 생애주기 일치 | +10 / 불일치 −10 |
| 크기(소/중/대) 일치 | +6 / 불일치 −7 |
| 등록한 알레르기 성분 포함 | **−38** (추천 목록에서도 제외) |
| 알레르기 성분 미포함 | +6 |
| 염려질환 일치 | 항목당 +7 (최대 2개) |
| 만성 신장질환 + 인 함량 | 0.6% 이하 +8 / 1.0% 이상 −12 |
| 슬개골 탈구·아토피 피부염 + 관련 성분 | 각 +5 |
| 췌장염 + 조지방 16% 이상 | −10 |
| 성분 평가 | 양호 항목당 +1.6 / 기준 이탈 항목당 −5 |
| 리뷰 평점 | (평점 − 4.3) × 10 |
| 리뷰 없음 | −4 |

최종 20~97점으로 보정합니다. 같은 상품이라도 보는 아이가 바뀌면 점수와 근거 문구가 함께 바뀝니다.

| 상품 | 보리 | 나비 |
| --- | --- | --- |
| 연어 그레인프리 올라이프 | **96** | – (강아지 전용) |
| 저알러지 오리&고구마 | **90** | – |
| 데일리 치킨&라이스 | **23** (알레르기 차단) | – |
| 관절 플러스 시니어 | **20** (어덜트 · 대형 · 닭고기) | – |

## 크기 기반 급여량 계산

IA v0.3의 프로필에는 체중이 없고 **크기(소형/중형/대형)**만 있습니다.
급여량 가이드는 크기 구간의 대표 체중으로 근사합니다.

| 크기 | 강아지 | 고양이 |
| --- | --- | --- |
| 소형 | 5kg | 3.5kg |
| 중형 | 15kg | 5.0kg |
| 대형 | 30kg | 7.0kg |

대표 체중으로 RER(휴식기 에너지 요구량)을 구하고 생애주기·중성화·활동량·체중관리 계수를 곱해
하루 필요 칼로리를 계산한 뒤, 상품의 100g당 열량으로 나눠 하루 급여량(g)을 냅니다.
화면에는 **"대표 체중 기준 근사값"**임을 명시했습니다.

IA의 '하루 급여 / 1개 / 1일 당 가격'도 카테고리별로 다르게 계산합니다.
사료는 하루 급여량 × 100g당 단가, 간식은 1개당, 영양제는 1일당 가격입니다.

## IA에서 확인이 필요해 보이는 지점

프로토타입을 만들며 발견한 것들입니다. 화면 위에도 표시해 두었습니다.

| 항목 | 내용 | 화면 |
| --- | --- | --- |
| **Apple 로그인 누락** | IA에는 구글·카카오·네이버만 있습니다. iOS 앱에서 제3자 소셜 로그인을 제공하면 App Store 심사 지침상 Apple 로그인도 함께 제공해야 합니다. 우선 넣어 두었습니다. | 로그인 |
| **체중 vs 크기 불일치** | 프로필에는 체중이 없는데 리뷰 필터 바텀시트에는 몸무게 레인지 슬라이더가 있습니다. 지금은 체형 필터만 실제로 동작합니다. | 기본 리뷰 필터 |
| 대표 반려동물 지정 방식 | 로그인마다 선택인지, 대표를 지정해 두는지 | 마이페이지 |
| 리뷰 사용기간 산정 | 구매일 자동 계산인지 직접 입력인지 | 리뷰 작성 |
| 결제 수단 정책 | 사전 등록 지원 여부, 결제 시점 변경 허용 여부 | 주문/결제 |
| 문의 유형 항목 | 배송/취소/반품/교환/결제/불량 확정 필요 | 문의하기 |
| 민감정보 처리 | 염려질환·앓고 있는 질병은 민감정보. 별도 동의·암호화 저장 필요 | 프로필 추가 |
| 자연어 검색 | 이전 기획(2.1.5-5)에 있었으나 IA v0.3에는 없습니다. 이번 프로토타입에서도 뺐습니다. | – |

## 알아두어야 할 점

- 모든 데이터는 목(mock)입니다. 서버 호출이 없고, 상태는 브라우저 `localStorage`에만 저장됩니다.
- 상품 14종, 리뷰 40여 건은 기능을 보여주기 위해 구성한 가상 데이터입니다. 실제 제품·브랜드가 아닙니다.
- 성분 해석 문구는 일반적인 영양 가이드라인을 참고한 예시이며, 의학적 조언이 아닙니다.
- 사진 업로드, 실제 결제, 배송 추적, 교환·반품은 범위 밖입니다.
- 주문 상태는 결제 후 경과일로 바뀝니다. 주문 내역 화면의 `3일 경과시키기` 버튼으로 시연합니다.
- 브랜드 컬러는 `#FF611D`이며 CSS 변수 `--brand`로 관리합니다.
