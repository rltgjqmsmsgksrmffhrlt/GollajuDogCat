# 취소·반품·교환 내역 조회

상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%202cb7659d7db782e29d10012cd6a587b2.md)
세부 그룹: 주문 관리
우선순위: 높음(2순위)
논의 필요: PD 논의 필요

> 마이페이지_주문·배송 확인 화면 내 "취소·반품·교환" 탭. 사용자가 신청을 마친 취소/반품/교환 건을 이력으로 조회하는 화면. 신규 신청을 작성하는 화면(`반품 교환.md`)과는 별개.

[헤더]

- 뒤로가기 버튼
    - [터치] 이전 화면(마이페이지)으로 이동
- 타이틀: "주문·배송 확인"

[탭]

- 주문내역 / 취소·반품·교환 토글
    - 탭 명칭은 "취소·반품·교환"으로 고정 (구 "취소·환불·교환" 표기 사용 금지)
    - [터치: 주문내역] '마이페이지_주문/배송 목록 조회' 화면과 동일한 리스트로 전환
    - [터치: 취소·반품·교환] 아래 내역 리스트로 전환

[본문]
[형식] 리스트형 취소·반품·교환 내역 (건별 카드)

- [표시] 날짜
    - 취소 건: **결제일** YY.MM.DD + 결제 시각 HH:MM (취소는 별도 신청 접수 절차가 없어 접수일이 존재하지 않음)
    - 반품/교환 건: **접수일** YY.MM.DD + 접수 시각 HH:MM
- [표시] 상태 뱃지
    - 취소 → "환불" (결제 금액 환불 처리 상태를 의미)
    - 반품 → "반품중" / "반품완료" 등 진행 단계별 라벨 (※ 정확한 라벨 체계는 디자인 확인 필요)
    - 교환 → "교환중" / "교환완료" 등 진행 단계별 라벨 (※ 정확한 라벨 체계는 디자인 확인 필요)
- [표시] 상품 대표 이미지, 상품명, 수량(예: "1개"), 결제 금액
    - 상품 옵션은 표시하지 않음 (백엔드 구조상 옵션 없음)
- 자세히 보기 버튼
    - [터치: 취소 건] '마이페이지_주문 상세 화면'으로 이동 (취소 상태 반영된 상세)
    - [터치: 반품/교환 건] '마이페이지_반품/교환 진행 상태 화면'으로 이동

[예외 / 논의 필요]

- 취소된 주문을 "주문내역" 탭(일반 주문 목록)에서도 계속 노출할지, 이 탭에서만 보여줄지 — 9/23 대화 기준 미확정, 디자인/PM 재확인 필요
- 한 주문에 상품이 여러 개인 상태에서 일부 상품만 반품 신청한 경우, 이 내역 리스트에 신청한 상품만 표시할지 주문 전체 상품을 표시할지 확인 필요
- 뱃지 라벨(환불/반품중/반품완료/교환중/교환완료 등) 최종 문구·색상 확정 필요
