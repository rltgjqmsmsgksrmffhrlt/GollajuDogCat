- 배송 요청 사항 드롭다운
    - [터치] 리스트 표시
        - [기본] 문 앞에 놓아주세요
        - 경비실에 맡겨주세요
        - 부재 시 전화 부탁드려요
        - 배송 전 미리 연락 주세요
        - 직접 받을게요
        - 직접 입력
            - [터치] 하단에 입력란 생성, 입력 가능 (100자 이내)
    - [목록 중 하나 터치] 입력됨
