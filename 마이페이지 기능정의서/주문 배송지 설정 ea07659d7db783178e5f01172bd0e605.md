# 주문 배송지 설정

기능그룹: 결제
기능 짧은 desciption: 터치 시 '마이페이지_배송지 변경 바텀시트' 이동
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%204527659d7db7838bbfa28129e9fb4142.md)
세부 그룹: 결제
우선순위: 보통(3순위)
논의 필요: PD 논의, 논의 완료

![image.png](image%2045.png)

- 배송지 변경하기 버튼
    - [터치] '마이페이지_배송지 설정 화면'으로 이동
- ‘마이페이지_배송지 설정 화면’
    - [표시] 배송지명, 기본 배송지 여부, 주소, 더보기 이모지
    - [목록 중에서 배송지 터치] 해당 배송지를 이번 주문의 배송지로 선택 (기본배송지 설정과는 별개, 1회성 선택)
    - 장소 추가 버튼
        - [터치] ‘마이페이지_배송지 추가/수정 화면’으로 이동
