# 장바구니 상품 조회

기능그룹: 장바구니
기능 짧은 desciption: 터치 시 ‘검색_상품 상세 화면’ 혹은 ‘상품 추천_상품 추천 상세 화면’으로 이동
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%209887659d7db782e4976401d0303a865f.md)
세부 그룹: 장바구니
우선순위: 높음(2순위)
논의 필요: PD 논의, 논의 완료

![image.png](image%209.png)

- 정렬 기준: 최신 등록 순
- 장바구니에 아무 상품도 등록되지 않았을 경우 : ‘아직 상품이 장바구니에 등록되지 않았어요.’
- 장바구니 최대 등록 가능한 상품 수: 무한대
- 상품 버튼(영역형)
    - [표시]
        - 상품명(최대글자수: 1줄 이내)
        - 옵션(최대 글자수: 영역 초과시 줄임말(…))
        - 대표 이미지
        - 판매가격(강조)
        - 정품가격(취소선 표시)
        - 개수
    - [터치] ‘상품 상세 화면’ 으로 이동
- [표시] 결제 금액(판매 가격+배송비), 판매가격, 배송비 순으로 표시
- 결제하기 버튼
    - [터치] ‘마이페이지_결제 화면’으로 이동
