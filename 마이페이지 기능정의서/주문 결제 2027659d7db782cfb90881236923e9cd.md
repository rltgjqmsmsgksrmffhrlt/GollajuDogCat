# 주문 결제

기능그룹: 결제
기능 짧은 desciption: 터치 시 '토스페이먼츠 결제 화면(타사)'으로 연결
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%204527659d7db7838bbfa28129e9fb4142.md)
세부 그룹: 결제
우선순위: 매우높음(1순위)
논의 필요: PD 논의, 논의 완료

| 8-1 | 결제 동의 체크 없이 '결제하기' 버튼을 터치할 시
**해결책: "결제 진행을 위해 약관에 동의해주세요" 안내 메시지를 표시하고 PG사 결제 화면으로 이동하지 않는다.** | 마이페이지_결제 화면 | 높음 |
| --- | --- | --- | --- |
| 8-2 | 결제하기' 버튼을 터치하는 순간, 상품 재고가 소진(동시 구매 경합)되었을 시
**해결책: "품절되었어요" 안내와 함께 토스페이먼츠 결제 화면으로 이동하지 않고 장바구니 화면으로 복귀시킨다. 장바구니 화면에 해당 상품 체크박스를 비활성화시킨다.** | 마이페이지_결제 화면 | 높음 |
| 9-1 | 토스페이먼츠 결제창에서 사용자가 결제를 취소하거나 창을 닫을 시
**해결책: 결제 화면으로 복귀시키고, 입력해두었던 배송지/전달사항/결제수단 선택값은 유지한다.** | 토스페이먼츠_PG사 결제 화면(외부) | 높음 |
| 9-2 | 토스페이 계정의 머니 잔액 또는 연결계좌 잔액 부족으로 결제 승인이 실패할 시
**해결책: "잔액이 부족해요" 안내 메시지를 표시하고 결제 화면으로 복귀시키고, 입력 선택값은 유지한다.** | 토스페이먼츠_PG사 결제 화면(외부) | 높음 |
| 9-3 | 토스페이 인증(생체인증/PIN) 단계에서 인증에 반복 실패할 시
**해결책: 토스페이먼츠 자체 실패 안내를 그대로 노출하고, 5회 초과 시 결제 화면으로 복귀시켜 재시도를 유도한다.** | 토스페이먼츠_PG사 결제 화면(외부) | 높음 |
| 9-4 | 토스페이먼츠 결제는 승인되었으나, 결제 완료 처리(주문 생성) 통신 중 네트워크·서버 오류가 발생할 시
**해결책: 결제는 완료 처리하고, 주문 상세 화면 노출은 재시도하거나 '마이페이지_결제 화면'을 딤처리 후 지연 안내 "주문 확인 중이에요"를 표시한다.** | 마이페이지_결제 화면 | 높음 |
