# 구매 확정

기능그룹: 주문관리
기능 짧은 desciption: 확인 시 주문 상태를 '구매확정'으로 즉시 전환
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%202cb7659d7db782e29d10012cd6a587b2.md)
세부 그룹: 주문 관리
우선순위: 높음(2순위)
논의 필요: PD 논의, 논의 완료

![image.png](image%2047.png)

- 구매확정 버튼
    - 배송완료 후 7일 이내, 미확정 상태에서만 노출
    - [터치] 확인 팝업 표시
        - [나중에 할게요] ‘마이페이지_주문 배송 내역 화면’으로 복귀
        - [확정하기] 확인 시 주문 상태를 '구매확정'으로 전환, ‘마이페이지_주문 배송 내역 화면’으로 복귀
    - 구매 확정 시
        - 반품/교환 불가능
        - 작성 가능한 리뷰 상에 등록, 리뷰 작성 가능
        - 상품별 반려동물 반응 체크 알림 카운트다운 시작
