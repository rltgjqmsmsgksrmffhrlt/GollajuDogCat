# 배송지 수정

기능그룹: 내 정보 관리
기능 짧은 desciption: 배송지 관련 데이터 수정
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%20fa17659d7db783288eb601bf3f3d4fe9.md)
세부 그룹: 배송지 관리
우선순위: 높음(2순위)
논의 필요: PD 논의, 논의 완료

- 기본적으로 배송지 추가와 동일하나, 기존 입력 데이터가 존재

![image.png](image%2023.png)

[본문]

- 배송지명 입력란
    - [터치] 텍스트 입력 (예: 집, 회사, 부모님댁)
- 받는 사람 입력란
    - [터치] 텍스트 입력
- 연락처 입력란
    - [터치] 숫자 입력, 하이픈 자동 처리
- 주소 검색 버튼
    - [터치] [배송지 주소 검색](%EB%B0%B0%EC%86%A1%EC%A7%80%20%EC%A3%BC%EC%86%8C%20%EA%B2%80%EC%83%89%20b217659d7db78285857f017ef1801d82.md) 으로 이동, 검색 결과 선택 시 주소 자동 입력
- 상세주소 입력란
    - [터치] 텍스트 입력 (동/호수 등)
- 배송 요청사항
    - [배송 요청사항 설정](%EB%B0%B0%EC%86%A1%20%EC%9A%94%EC%B2%AD%EC%82%AC%ED%95%AD%20%EC%84%A4%EC%A0%95%202187659d7db783ef864681264e5eb1ea.md) 참고
- 기본배송지로 설정 체크박스
    - [터치] 체크 시 저장 시점에 기본배송지로 지정
- 입력 완료 버튼
    - [터치] 필수값(배송지명/받는사람/연락처/주소) 유효성 검사
    - [검사 통과] 저장 후 '마이페이지_배송지 관리 화면'으로 이동
    - [검사 실패] 미입력 항목 안내 메시지 표시
