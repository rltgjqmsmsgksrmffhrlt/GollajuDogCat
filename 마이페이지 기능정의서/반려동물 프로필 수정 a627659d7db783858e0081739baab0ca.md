# 반려동물 프로필 수정

기능그룹: 반려동물 프로필
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%203e27659d7db783deb0a58106a7fedb02.md)
세부 그룹: 프로필
우선순위: 보통(3순위)
논의 필요: PD 논의, 논의 완료

![image.png](image%2033.png)

- 이미지 수정 버튼
    - [터치] 시스템 사진 갤러리 표시
    - 주의사항: 사진 갤러리 접근 권한 확인 필요
- 이름 수정 버튼
    - [터치] '마이페이지_이름 정보 수정 화면'으로 이동
- 몸무게 수정 버튼
    - [터치] '마이페이지_몸무게 정보 수정 화면'으로 이동
- 건강 수정 버튼
    - [터치] '마이페이지_건강 정보 수정 화면'으로 이동
- 반려동물 버튼
    - [터치] 각 반려동물 프로필로 이동
- 반려동물 추가 버튼
    - [터치] '마이페이지_프로필 추가 화면'으로 이동
