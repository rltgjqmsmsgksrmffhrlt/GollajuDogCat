# 재입고 알림

기능그룹: 주문관리
기능 짧은 desciption: PUSH 알림, 재입고 여부
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%202cb7659d7db782e29d10012cd6a587b2.md)
세부 그룹: 재입고 알림
우선순위: 보통(3순위)
논의 필요: PD 논의, 논의 완료

![image.png](image%2014.png)

- 등록
    - 상품 상세 화면에서 결제 할 때 품절이 되는 경우에 재입고 등록 여부 버튼 등장
- 알림
    - 재입고가 되면, PUSH 알림으로 알림
- 검색 버튼(영역형)
    - [터치] 재구매 등록된 상품 내에서 검색
- 상품 더 찾아보기 버튼
    - [터치] ‘상품 추천 화면’으로 이동

[상품 별 기능]

- [표시] 상품 대표 이미지, 상품명, 상품 옵션, 판매 가격
- 상품 확인
    - 상품 터치 시 ‘상품 상세 화면’으로 이동
- 삭제 버튼
    - 터치 시 해당 화면에서 재입고 알림 설정되어 있는 상품 제거 가능
