# 배송지 삭제

기능그룹: 내 정보 관리
기능 짧은 desciption: 삭제 확인 팝업 확인 시 삭제
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%20fa17659d7db783288eb601bf3f3d4fe9.md)
세부 그룹: 배송지 관리
우선순위: 낮음(4순위)
논의 필요: PD 논의, 논의 완료

![image.png](image%2042.png)

- [집, 회사인 주소] 배송지 삭제버튼 없음(삭제 불가능, 수정만 가능)
- [집, 회사가 아닌 주소에서만 등장] 배송지 삭제 버튼
    - [터치] 삭제 확인 팝업 표시
    - [확인 선택] 목록에서 해당 배송지 제거
    - [취소] 유지
