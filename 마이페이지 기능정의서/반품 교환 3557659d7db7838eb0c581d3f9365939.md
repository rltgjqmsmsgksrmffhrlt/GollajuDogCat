# 반품/교환

기능그룹: 주문관리
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%202cb7659d7db782e29d10012cd6a587b2.md)
세부 그룹: 주문 관리
우선순위: 매우높음(1순위)
논의 필요: PD 논의, 논의 완료

화면 필요

**[상단]**

- 뒤로가기 버튼
    - [터치] 이전 화면(주문 상세)으로 이동

**[신청 유형 선택]**

- 유형 드롭다운
    - [표시] 진입 시 전달받은 유형(취소/반품/교환)을 기본값으로 표시
    - [터치] 취소 / 반품 / 교환 중 선택 변경 가능

**[상품 정보]**

- 선택 상품 정보
    - [표시] 대표 이미지, 상품명, 옵션, 수량, 결제금액

**[사유 선택]**

- 사유 라디오 버튼
    - 단순변심
    - 상품 하자/불량
    - 배송 지연
    - 기타

**[상세 내용 및 첨부]**

- 이미지 업로드
    - [터치] 사진 첨부 (최대 3장)
- 텍스트 입력란
    - [입력] 상세 사유 및 기타 문의 작성 (자유 기술, 최대 300자)

**[하단]**

- 신청하기 버튼
    - [터치] 접수 완료 후 '마이페이지_주문 상세 화면'으로 이동
