# 회원 정보 수정

기능그룹: 내 정보 관리
기능 짧은 desciption: 각 정보마다 수정 화면으로 이동
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%20fa17659d7db783288eb601bf3f3d4fe9.md)
세부 그룹: 내 정보 관리
우선순위: 낮음(4순위)
논의 필요: PD 논의, 논의 완료

- [터치]
    - 이미지 : 시스템 사진 갤러리 표시
        - 주의사항: 사진 갤러리 접근 권한 확인 필요
    - 닉네임: 입력란과 문자 키패드 등장
        - 변경 사항 없을 시 입력 완료 비활성화
    - 이름 : 입력란과 문자 키패드 등장
        - 변경 사항 없을 시 입력 완료 비활성화
    - 생년월일 : 입력란과 문자 키패드 등장
        - 변경 사항 없을 시 입력 완료 비활성화
    - 휴대폰 번호 : 통신사 선택 토글과 전화번호 입력란, 숫자 키패드 등장, 인증 버튼, 재전송 버튼
        - 인증 터치 시, (시스템) 인증번호 발송, 자동 입력, 재전송 버튼 노출
        - 변경 사항 없을 시 입력 완료 비활성화
    - 내 아이들:  각 반려동물 ‘마이페이지_프로필 화면’ 이동,  각 반려동물 사진으로
    - 배송지 리스트 터치 : 각 배송지의 ‘마이페이지_배송지 추가/수정 화면’으로 이동
