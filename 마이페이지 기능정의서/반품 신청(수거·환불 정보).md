# 반품 신청 (수거·환불 정보 입력)

기능그룹: 주문관리
상위 항목: 반품 교환 (반품/교환 작성 화면의 후속 단계 — 사유·사진 입력 완료 후 진입)
세부 그룹: 주문 관리
우선순위: 매우높음(1순위)
논의 필요: PD 논의 필요

> 반품/교환 작성 화면(`반품 교환.md`)에서 사유·사진 입력을 마친 뒤 진입하는 화면으로 추정. 수거 일정과 환불 예상 금액을 확인하고 최종 제출하는 단계.

[헤더]

- 뒤로가기 버튼
    - [터치] 이전 화면(반품 사유 작성 화면)으로 이동
- 타이틀: "반품 신청"

[수거 희망일] (필수)

- 수거 희망일 선택 버튼 2개 (예: "9/24(목)")
    - [표시] 선택 가능한 수거 희망일 목록 중 디폴트 값 표시
    - ※ 버튼 2개가 "기간(시작~종료)"을 의미하는지, 서로 다른 상품 각각의 수거일을 의미하는지 화면만으로는 불명확 — 확인 필요
- 안내 문구 (고정 텍스트)
    - "1~2일 안에 기사님이 상품을 수거해요. 상태 확인이 끝나면 바로 환불해드릴게요."

[수거 요청사항] (선택)

- 텍스트 입력란
    - [입력] 자유 기술, placeholder "요청사항을 입력해주세요"

[환불 안내]

- [표시] 반품 대상 상품명 · 수량 (예: "강아지 눈 영양제 ... · 1개")
- [표시] 금액 내역
    - 상품 금액
    - 배송비
    - 반품비 (차감, 음수 표시. 예: "-3,000원")
- [표시] 환불 예상 금액 = 상품 금액 + 배송비 - 반품비 (강조 표시)
- [표시] 환불 수단: 결제에 사용한 수단 로고 + 환불 금액 (예: 토스페이 로고 / 40,900원)

[하단]

- 반품 신청 완료하기 버튼
    - [비활성화] 필수 항목(수거 희망일) 미선택 시
    - [터치] 반품 신청 접수 처리, 완료 후 '마이페이지_취소·반품·교환 내역 조회' 화면으로 이동

[예외 / 논의 필요]

- **반품비 부과 로직 미정의**: 현재 `반품 교환.md`에는 반품비 관련 내용이 전혀 없음. 사유(단순변심/상품하자/배송지연/기타)에 따라 반품비를 차등 부과하는지(예: 단순변심만 유료, 하자는 무료) 백엔드·PM 확인 필요
- 이 화면과 `반품 교환.md`(유형 선택/사유 선택/사진 첨부)의 순서 관계 — 사유 작성 화면 다음 단계가 맞는지, 두 화면을 하나의 문서로 통합할지 확인 필요
- 수거 희망일 버튼 2개의 정확한 의미 확인 필요
- 교환 신청에도 동일한 수거·환불(또는 배송) 안내 단계가 있는지 확인 필요 (교환은 환불이 아니라 새 상품 발송이므로 이 화면과 다른 구성일 가능성)
