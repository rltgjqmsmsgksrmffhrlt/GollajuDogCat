# 대상 상품 추가/제거

기능그룹: 타임딜
기능 짧은 desciption: 터치 시 상품을 선택 리스트에 추가하거나 리스트에서 제거
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%2015d7659d7db7827f91b481fe08052526.md)
세부 그룹: 타임딜 등록
우선순위: 높음(2순위)

선택된 상품 리스트 (상품명, 정상가, 카테고리)

- 추가 버튼
    - [터치] 검색 결과 상품을 선택 리스트에 추가, 선택된 상품 수 카운트 증가
- 제거 버튼
    - [터치] 선택 리스트에서 해당 상품 제외, 선택된 상품 수 카운트 감소
