# 상품별 판매 조건 설정

기능그룹: 타임딜
기능 짧은 desciption: 선택 상품별 한정 수량·할인율 입력 시 할인가 자동 계산
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%2015d7659d7db7827f91b481fe08052526.md)
세부 그룹: 타임딜 등록
우선순위: 매우높음(1순위)

- 한정 수량 입력란 (상품별 개별 입력, 기본값 없음)
    - [터치] 입력란 활성화, 숫자 입력 가능
- 할인율 입력란 (상품별 개별 입력, %)
    - [터치] 입력란 활성화, 숫자 입력 가능
        - [입력 완료] 할인 가격 자동 계산 표시 (= 정상가 × (1 − 할인율))
