# 임시저장 / 등록

기능그룹: 타임딜
기능 짧은 desciption: 터치 시 입력값을 임시 저장하거나 유효성 검사 후 딜을 등록
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%2015d7659d7db7827f91b481fe08052526.md)
세부 그룹: 타임딜 등록
우선순위: 매우높음(1순위)

- 임시저장 버튼
    - [터치] 입력값을 임시 상태로 저장, 목록에는 미노출
- 등록 버튼
    - [터치] 필수값 유효성 검사 수행
        - 통과 시
            - '관리자_타임딜 관리 화면(목록)'에 '예정' 상태로 등록
        - 미통과 시
            - 오류 메시지 노출, 해당 입력란 강조 표시
