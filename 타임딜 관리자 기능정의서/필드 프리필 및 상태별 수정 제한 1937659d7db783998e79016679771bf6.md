# 필드 프리필 및 상태별 수정 제한

기능그룹: 타임딜
기능 짧은 desciption: 저장된 딜을 상태에 따라 전체/일부 필드 수정 가능 여부 분기
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%2015d7659d7db7827f91b481fe08052526.md)
세부 그룹: 타임딜 상세/수정
우선순위: 낮음(4순위)

- 등록 화면과 동일한 필드에 기존 값 프리필(pre-fill) 표시
- 예정 상태인 경우
    - 전체 필드 수정 가능
- 진행중 상태인 경우
    - 시작일시, 대상 상품 종류 수정 불가 (잠금 아이콘 표시)
    - 한정 수량·할인율 등 상품별 판매 조건은 수정 가능
- 종료 상태인 경우
    - [터치] 본 화면 대신 '관리자_타임딜 결과 리포트 화면'으로 이동
