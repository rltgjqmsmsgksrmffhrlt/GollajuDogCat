# 기본 정보 입력

기능그룹: 타임딜
기능 짧은 desciption: 딜 이름, 시작 일시, 진행 시간 입력 시 종료 일시 자동 계산
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%2015d7659d7db7827f91b481fe08052526.md)
세부 그룹: 타임딜 등록
우선순위: 매우높음(1순위)

- 딜 이름 입력란
    - [터치] 입력란 활성화, 텍스트 입력 가능
- 시작 일시 선택 (날짜/시각, 10분 단위, 기본값 정시)
    - [날짜 영역 터치] 캘린더 표시
        - [날짜 선택] 날짜 입력됨
    - [시각 영역 터치] 스크롤 표시
        - [시각 확인 터치] 시각 입력됨
- 진행 시간 선택 (10분 단위, 기본값 30분)
    - [터치] 스크롤 표시
        - [확인 터치] 진행 시간 입력됨
- 종료 일시 자동 계산 표시 (읽기 전용)
    - 시작일시 + 진행시간 값으로 자동 반영
