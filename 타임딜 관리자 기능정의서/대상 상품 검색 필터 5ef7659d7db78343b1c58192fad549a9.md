# 대상 상품 검색/필터

기능그룹: 타임딜
기능 짧은 desciption: 카테고리 검색, 필터, 선정 기준으로 대상 상품 후보 조회
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%2015d7659d7db7827f91b481fe08052526.md)
세부 그룹: 타임딜 등록
우선순위: 높음(2순위)

- 검색 입력란
    - [터치] 검색 영역 활성화, 키워드 입력 가능
- 카테고리 필터 드롭다운 (기본값: 모두 / 선택지: 모두, 사료, 간식, 영양제)
    - [터치] 드롭다운 리스트 표시
        - [선택] 해당 카테고리 상품만 검색 결과에 표시
- 선정 기준 드롭다운 (기본값: 인기순)
    - 선택지: 인기순(기본), 잘 안 팔리는 순, 신상품순, 마진율 높은 순, 유통기한 임박순, 최근 리뷰 급증순, MD 추천(수동)
    - [터치] 드롭다운 리스트 표시
        - [선택] 선택 기준에 따라 정렬된 상품 후보 노출
