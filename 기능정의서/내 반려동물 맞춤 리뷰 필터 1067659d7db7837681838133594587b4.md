# 내 반려동물 맞춤 리뷰 필터

기능 짧은 desciption: 현재 선택된 반려 동물 프로필 기준, 유사 조건의 반려 동물이 작성한 리뷰 필터링
기능그룹: 리뷰
상위 항목: 리뷰 필터 부분 (%EB%A6%AC%EB%B7%B0%20%ED%95%84%ED%84%B0%20%EB%B6%80%EB%B6%84%206c57659d7db783c4baa3012b5c8cc915.md)
세부 그룹: 맞춤 리뷰 필터
우선순위/논의 사항: 보통(3순위)

- `‘내 반려동물 맞춤보기’`

![image.png](image%203.png)

- 현재 선택된 반려동물 프로필을 기준으로 조건이 유사한 반려동물이 작성한 리뷰를 필터링하여 제공
    - 라디오 버튼 형식 (스와이프 형식)
- 선택된 반려동물 프로필의 **종, 나이, 체중, 중성화 여부, 건강 관심정보** 등을 비교 조건으로 활용
- 최초 진입 시 맞춤 리뷰 필터는 적용하지 않고 전체 리뷰를 기본 노출
- 활성화한 경우: 반려동물 프로필의 조건에 맞는 리뷰만 조회 (교집합)
