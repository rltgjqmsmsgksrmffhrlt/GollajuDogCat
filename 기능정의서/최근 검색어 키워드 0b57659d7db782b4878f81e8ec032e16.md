# 최근 검색어 키워드

Function ID: FUNC-003-02
기능 짧은 desciption: 최근 검색어 노출
기능그룹: 검색
상위 항목: 검색 페이지 (%EA%B2%80%EC%83%89%20%ED%8E%98%EC%9D%B4%EC%A7%80%202867659d7db782c9a29881c3101fdd93.md)
세부 그룹: 최근 검색어 조회
우선순위/논의 사항: 보통(3순위)

![image.png](image%201.png)

- 노출되는 최근 검색어는 최대 5개
- 검색 화면 진입 시 최근 검색어 영역 노출
- 최근 검색어는 검색 실행 완료 기준으로 저장
- 최신 검색어를 우선으로 최대 5개까지 노출
- 동일 검색어를 다시 검색한 경우 중복 저장하지 않고 최신 검색어로 순서 갱신
- 최근 검색어 선택 시 해당 키워드로 즉시 재검색
- 개별 검색어 삭제 가능 (각 키워드에는 X버튼 존재)
- 전체 삭제 가능, 클릭 시모든 최근 검색 기록 삭제
- 최근 검색 이력이 없는 경우 최근 검색어 키워드 Empty view
    - “최근 검색된 키워드가 없습니다.”
