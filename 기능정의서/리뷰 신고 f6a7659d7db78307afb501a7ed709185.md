# 리뷰 신고

기능 짧은 desciption: 신고 버튼 선택 시 리뷰 신고 화면으로 이동, 사유 선택하고 신고할 수 있도록 조치
기능그룹: 리뷰
상위 항목: 리뷰 탭 | 리뷰 페이지 (%EB%A6%AC%EB%B7%B0%20%ED%83%AD%20%EB%A6%AC%EB%B7%B0%20%ED%8E%98%EC%9D%B4%EC%A7%80%208ba7659d7db7838da27481497c72c3db.md)
세부 그룹: 리뷰 상세
우선순위/논의 사항: 매우낮음(5순위)

- 리뷰의 신고 버튼 선택 시 신고 화면으로 이동 (노션 화면을 적용할 예정입니다.)
- 신고 사유 목록
    - 욕성/비방
    - 광고/홍보
    - 상품과 무관
    - 개인정보 노출
    - 기타 (100자 이내)
- 신고 사유 선택 후 신고 제출 가능
- 필수 신고 사유가 선택되지 않은 경우 제출 불가
- 신고 완료 시 완료 안내 제공
    - ‘신고가 접수되었습니다.’ 토스트 메세지
- 동일 사용자의 동일 리뷰 반복 신고가 될 경우 ‘이미 신고한 리뷰입니다’ 토스트 메시지 노출
