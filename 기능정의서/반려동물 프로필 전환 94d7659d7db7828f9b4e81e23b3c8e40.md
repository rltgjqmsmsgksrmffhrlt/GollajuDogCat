# 반려동물 프로필 전환

기능 짧은 desciption: 반려 동물 프로필 선택 시 → 추가되어 있는 다른 프로필로 전환 가능
기능그룹: 메인화면
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%20ed87659d7db78231becb8149a3180ae4.md)
세부 그룹: 프로필 영역
우선순위/논의 사항: 보통(3순위)

![image.png](image%2026.png)

- 등록된 반려동물 프로필을 선택하여 현재 기준 프로필을 변경할 수 있다.
- 선택된 프로필은 활성 상태로 표시한다. (가장 맨 앞으로 표시)
- 프로필 변경 시 메인 화면 내 개인화 추천, AI 추천, 적합도 등 프로필 기반 콘텐츠를 선택한 반려동물 기준으로 갱신한다.
- 프로필이 1개인 경우 해당 프로필을 기본 선택 상태로 제공한다.
