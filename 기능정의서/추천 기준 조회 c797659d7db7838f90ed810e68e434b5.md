# 추천 기준 조회

기능 짧은 desciption: 현재 반려동물에게 중요한 상품 선택 기준을 태그 형태로 제공
기능그룹: 상품 추천
상위 항목: 상품 추천 페이지  (%EC%83%81%ED%92%88%20%EC%B6%94%EC%B2%9C%20%ED%8E%98%EC%9D%B4%EC%A7%80%207eb7659d7db7827c8ec80149fc558d78.md)
세부 그룹: 추천 상품
우선순위/논의 사항: 낮음(4순위)

- 현재 선택된 반려동물에게 중요한 상품 선택 기준을 태그 형태로 제공한다.
- 추천 기준은 건강 상태, 관심 건강정보, 나이, 체중 등 추천 로직에 실제 반영된 주요 조건을 기준으로 노출한다.
- 추천 기준 태그는 복수 개 노출(최대 2개) 가능하다. - 최대 5글자
- 반려동물 프로필이 변경되면 추천 기준 태그를 갱신한다.

예시 태그

`#관절건강`

`#저지방`

`#노령견`
