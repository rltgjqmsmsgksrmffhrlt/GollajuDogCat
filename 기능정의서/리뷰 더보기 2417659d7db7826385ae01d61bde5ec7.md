# 리뷰 더보기

기능 짧은 desciption: 리뷰 내용이 기본자(100자)를 초과하는 경우, ‘더보기’ 버튼 제공, 선택 시 전체 리뷰 내용을 펼쳐서 조회
기능그룹: 리뷰
상위 항목: 리뷰 탭 | 리뷰 페이지 (%EB%A6%AC%EB%B7%B0%20%ED%83%AD%20%EB%A6%AC%EB%B7%B0%20%ED%8E%98%EC%9D%B4%EC%A7%80%208ba7659d7db7838da27481497c72c3db.md)
세부 그룹: 리뷰 상세
우선순위/논의 사항: 낮음(4순위)

- 리뷰 본문이 기본 노출 영역을 초과할 경우 일부 내용만 노출하고 `더보기` 버튼 제공
- 더보기 선택 시 해당 리뷰의 전체 본문을 펼쳐서 제공
- 전체 내용 노출 후 접기 기능 제공 여부는 정책에 따라 적용
