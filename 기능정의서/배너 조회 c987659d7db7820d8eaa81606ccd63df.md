# 배너 조회

기능 짧은 desciption: 메인 배너 영역에 프로모션 또는 콘텐츠 배너 노출
기능그룹: 메인화면
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%20ed87659d7db78231becb8149a3180ae4.md)
세부 그룹: 배너 광고
우선순위/논의 사항: 보통(3순위)

![image.png](image%2037.png)

- 정적 데이터로 고정할 예정(MVP)
- 메인 화면에 서비스 운영 정책에 따른 프로모션/이벤트/콘텐츠 배너를 제공한다.
- 복수 배너가 존재하는 경우 슬라이드(캐러셀) 형태로 노출할 수 있다.
- 노출 가능한 배너가 없는 경우 해당 영역 미노출 여부는 정책에 따라 적용한다.
