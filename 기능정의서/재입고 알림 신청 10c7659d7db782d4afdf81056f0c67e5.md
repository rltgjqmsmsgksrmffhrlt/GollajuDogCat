# 재입고 알림 신청

기능 짧은 desciption: 상품 상세 내 ‘재입고 알림 신청’ 과 동일
기능그룹: 상품 추천
상위 항목: 상품 추천 페이지  (%EC%83%81%ED%92%88%20%EC%B6%94%EC%B2%9C%20%ED%8E%98%EC%9D%B4%EC%A7%80%207eb7659d7db7827c8ec80149fc558d78.md)
세부 그룹: 추천 상품 상세
우선순위/논의 사항: 낮음(4순위)

- 상품이 품절된 경우 `장바구니` 및 `바로 구매` 버튼 대신 `재입고 알림` 버튼 제공
- 재입고 알림 버튼 선택 시 해당 상품의 재입고 알림 신청
- 이미 신청한 상품인 경우 신청 완료 상태 표시
- 재입고 발생 시 사용자에게 알림 제공
- 재입고 알림 취소 기능 제공 여부는 정책에 따라 적용
