# 상품 추천 근거 조회

기능 짧은 desciption: 해당 반려동물에게 상품을 추천하는 이유 및 주의 사항 제공
기능그룹: 상품 추천
상위 항목: 상품 추천 페이지  (%EC%83%81%ED%92%88%20%EC%B6%94%EC%B2%9C%20%ED%8E%98%EC%9D%B4%EC%A7%80%207eb7659d7db7827c8ec80149fc558d78.md)
세부 그룹: 추천 근거
우선순위/논의 사항: 보통(3순위)

**기능 상세**

- 각 추천 상품별로 해당 반려동물에게 추천하는 이유와 주의사항을 요약하여 제공한다.
- 추천 근거는 반려동물 프로필과 상품 성분/영양/기능 정보 비교 결과를 기반으로 생성한다.
- 추천 근거는 기본 노출 개수 또는 영역 제한 내에서 요약 제공한다.
- 주의가 필요한 성분 또는 조건이 있는 경우 함께 노출한다.

**예시**

- `관절 건강 관리에 도움이 되는 성분이 포함되어 있어요.`
- `현재 체중 기준 지방 함량이 적절해요.`
- `닭고기 알레르기 이력이 있다면 주의가 필요해요.`
