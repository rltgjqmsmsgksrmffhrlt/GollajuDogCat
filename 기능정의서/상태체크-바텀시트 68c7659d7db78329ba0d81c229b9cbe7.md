# 상태체크-바텀시트

기능 짧은 desciption: 바텀 시트 영역
기능그룹: 메인화면
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%20ed87659d7db78231becb8149a3180ae4.md)
세부 그룹: 최근 구매 상품
우선순위/논의 사항: 높음(2순위)

- ‘`$W`’의 반응 남기기 클릭 시, 나타나느 바텀 시트
- 상단-반려동물 프로필에 맞는 이름
- 상품 카드
    
    <aside>
    
    상품 대표 이미지
    
    상품명
    
    구매 후 N일
    
    N번쨰 구매
    
    </aside>
    
- 잘 맞았어요 | 그냥 그랬어요 | 안 맞았어요 버튼
- 체크 박스: ‘아직 판단하기에는 일러요 (며칠 더 지켜볼게요)’
    - 체크 박스 클릭 - 일주일 뒤 리마인드 알림
- 각 버튼 중 하나 클릭 시 하단 `등록하기` 버튼 활성화
- 아무것도 클릭 안 했을 시 하단 `등록하기` 버튼 비활성화
- ‘등록하기’ 버튼 클릭 시, 반응이 등록되었다는 바텀 시트로 나타남
    - 계속 쇼핑하기 - 바텀시트가 사라지고, 메인 화면으로 나타남
    - 자세히 보러 갈게요 - `마이페이지 내 반응 입력하기 화면`으로 이동
- **반응이 등록된 경우, 해당 데이터 이후 추천에 반영**
