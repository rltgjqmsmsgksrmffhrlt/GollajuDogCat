# 장바구니

- 장바구니 버튼 선택 시 현재 상품을 장바구니에 추가
- 필수 옵션이 있는 상품은 옵션 선택 후 추가 가능 (필수)
    - 바텀시트로 옵션 선택
        - 상품 옵션
- 옵션이 없더라도 상품 갯수 추가 바텀시트 (필수)
    - 기본 수량은 1개로 설정
- 동일 상품 및 동일 옵션이 장바구니에 존재하는 경우 수량 증가 또는 중복 추가 정책 적용
- 장바구니 추가 완료 후 완료 안내 제공 (’장바구니에 상품을 넣었어요!’ 토스트 메세지 3초 노출)

## 바로구매

- 바로 구매 선택 시 현재 선택된 상품/옵션/수량 정보를 기준으로 주문 화면으로 이동
- 필수 옵션 미선택 시 옵션 선택을 안내
    - 옵션 선택 바텀 시트
- 옵션이 없더라도 상품 갯수 추가 바텀시트 (필수)
    - 기본 수량은 1개로 설정
- 품절 상품은 구매 버튼 비활성화

## 좋아요

- 해당 상품이 ‘좋아요 리스트’에 존재하지 않은 경우
    - 기본: 눌려 있지 않음
    - 좋아요를 누를 시 ‘좋아요’ 버튼이 눌리고, ‘해당 상품을 찜 목록에 담았어요!’ 의 토스트 메세지 노출 (3초)
- 해당 상품이 이미 ‘좋아요 리스트’에 존재하는 경우
    - 기본: 눌려 있음
    - 이때 좋아요를 누를 시 ‘좋아요 리스트’ 데이터에서 삭제
