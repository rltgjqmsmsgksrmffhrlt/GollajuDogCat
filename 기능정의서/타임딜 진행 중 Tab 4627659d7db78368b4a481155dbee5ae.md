# 타임딜 진행 중 Tab

기능그룹: 타임딜
상위 항목: 메인 페이지 내 타임딜 섹션 → 타임딜 화면 (%EB%A9%94%EC%9D%B8%20%ED%8E%98%EC%9D%B4%EC%A7%80%20%EB%82%B4%20%ED%83%80%EC%9E%84%EB%94%9C%20%EC%84%B9%EC%85%98%20%E2%86%92%20%ED%83%80%EC%9E%84%EB%94%9C%20%ED%99%94%EB%A9%B4%206937659d7db782a6bb1e01c6c57adeb6.md)
세부 그룹: 진행 중
우선순위/논의 사항: 낮음(4순위)

![image.png](image%2012.png)

- 상단 종료까지 남은 시간 (실시간 카운트)
- 상품 카드 나열
    
    <aside>
    
    - 상품 대표 이미지
    - 상품명
    - 기존 가격
    - 할인율
    - 판매가(할인된 가격)
    - 1일 섭취 기준 가격
    </aside>
    
- 상품 카드 클릭 시 해당 상품 상세 페이지로 이동
- 상품 카드 내 각 장바구니 버튼
    - 장바구니 버튼 클릭 시 ‘장바구니에 담겼어요’ 토스트 메세지
    - 장바구니 버튼 클릭 시 장바구니 버튼이 체크버튼이 되며 비활성화 (두 번 누르지 못함)
    - 옵션이 있을 시 옵션 선택 바텀 시트로 올라옴
    - 1인 1개의 상품만 구매 가능
- 품절 임박 | 품절의 경우 상품 대표이미지에 tag 추가
- 품절 상품의 경우 흐린 처리되며 장바구니 | 상품 카드 비활성화
