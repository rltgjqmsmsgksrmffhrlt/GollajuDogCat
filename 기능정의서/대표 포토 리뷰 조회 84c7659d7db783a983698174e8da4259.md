# 대표 포토 리뷰 조회

기능 짧은 desciption: 상품에 등록된 포토 리뷰 중 대표 이미지 4개로 노출, 전체 포토 리뷰수 함께 제공 (최신순 4개)
기능그룹: 리뷰
상위 항목: 리뷰 탭 | 리뷰 페이지 (%EB%A6%AC%EB%B7%B0%20%ED%83%AD%20%EB%A6%AC%EB%B7%B0%20%ED%8E%98%EC%9D%B4%EC%A7%80%208ba7659d7db7838da27481497c72c3db.md)
세부 그룹: 포토 리뷰
우선순위/논의 사항: 보통(3순위)

![image.png](image%2024.png)

- 이미지가 등록된 리뷰를 기준으로 대표 포토 리뷰 제공
- 최대 4개의 대표 리뷰 이미지 노출
- ~~등록된 포토 리뷰 수를 함께 표시~~
- 대표 이미지 선택 시 해당 포토 리뷰 상세 화면으로 이동
- 포토 리뷰가 없는 경우 해당 영역 미노출
- 대표 이미지 옆 [전체보기] 버튼 노출 (전체 보기 버튼은 포토 리뷰 수에 관계 없이 노출)
