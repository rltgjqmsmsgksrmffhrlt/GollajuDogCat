# 상품 카테고리 필터 탭

기능 짧은 desciption: 상단 카테고리/상품 필터 선택 시 해당 조건에 맞는 상품 목록 제공 (탭 형태)
기능그룹: 메인화면
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%20ed87659d7db78231becb8149a3180ae4.md)
세부 그룹: 상단 카테고리 필터
우선순위/논의 사항: 매우높음(1순위)

![image.png](image%2045.png)

- 메인 상단에 상품 카테고리 필터를 제공한다.
- 전체 / 사료 / 간식 / 영양제 등 서비스에서 정의한 카테고리를 제공한다.
- 최초 진입 시 기본 카테고리(전체)를 선택 상태로 제공한다.
    - ‘전체’로 되어 있는 경우가 기본 메인 페이지임
- 카테고리 선택 시 해당 카테고리에 속하는 상품 콘텐츠로 목록을 갱신한다.
    - `메인화면_상품리스트_상품 목록 조회` 명세 확인
- 선택된 카테고리는 활성 상태로 표시한다.
