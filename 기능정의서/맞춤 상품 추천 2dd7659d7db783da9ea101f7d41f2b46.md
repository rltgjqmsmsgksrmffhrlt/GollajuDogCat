# 맞춤 상품 추천

기능 짧은 desciption: 현재 선택된 반려동물 프로필 기준 추천 상품 제공
기능그룹: 메인화면
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%20ed87659d7db78231becb8149a3180ae4.md)
세부 그룹: 상품 추천
우선순위/논의 사항: 매우높음(1순위)

![image.png](image%207.png)

- AI가 골라주는 < 반려동물 이름 > 맞춤 상품
- 현재 선택된 반려동물 프로필 기준의 맞춤 추천 상품 일부를 메인 화면에 제공한다.
- 추천 상품은 서비스의 `상품 추천` 로직을 따른다.
- 대표 추천 상품 또는 일부 상품만 노출하며 전체 추천 상품은 별도 추천 화면에서 조회한다.
    - ‘더보기’ 클릭 시 `추천 화면`으로 이동
        - ‘`상품 추천`’ 명세 참고
- 프로필 변경 시 추천 결과를 갱신한다.
- 상품 카드 나열
- 상품 카드를 클릭할 경우 해당 상품 상세 페이지로 이동
    - `상품 상세` 명세 참고
    
    <aside>
    
    - 상품 대표 이미지
        - 좋아요 버튼
        - 상품 적합도
    - 상품명
    - 할인률
    - 가격
    - 개 당/g 당 가격
    - 별점
    - 후기 갯수
    </aside>
    
- 선택된 반려동물 프로필이 있는 경우 적합도 또는 맞춤 정보를 함께 제공할 수 있다.
- 품절 상품은 품절 상태를 표시한다.
- 카드 내 좋아요 버튼을 누르면, 버튼이 활성화되고 해당 상품의 내용이 ‘좋아요’ 페이지로 이동
- 적합도의 경우 AI가 판단한 현재 프로필 상 반려동물과의 적합도
    - 프로필을 변경할 경우 이에 맞춰 적합도 및 상품이 업데이트
