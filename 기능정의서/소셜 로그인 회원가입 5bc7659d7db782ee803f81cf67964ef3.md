- 회원가입
    - 회원가입 성공 시, 유저의 기본 정보가 입력되어야 합니다.
    - 닉네임 입력 화면
        - 기본 닉네임(졸린고양이17 등)
        - 기본 닉네임 format = (관형어) + (동물 명사) + (숫자) 랜덤 조합- 확인필요
            - 관형어
                
                졸린, 신나는, 행복한, 포근한, 말랑한, 귀여운, 사랑스러운, 활발한, 씩씩한, 용감한, 호기심많은, 장난꾸러기, 느긋한, 다정한, 순한, 반짝이는, 따뜻한, 폭신한, 똑똑한, 재빠른, 새침한, 해맑은, 꼬물꼬물한, 통통한, 쪼꼬만, 하찮은, 동그란, 순수한, 배고픈, 배부른, 토실토실한, 오물거리는
                
            - 동물 명사
                - 현재 MVP 버전은 주로 강아지 | 고양이지만, 다양성을 위해 전체적인 반려동물 | 반려동물이 아니더라도 귀여운 느낌의 동물 이름을 닉네임으로 활용
                
                강아지, 고양이, 토끼, 햄스터, 기니피그, 고슴도치, 앵무새, 카나리아, 거북이, 페럿, 친칠라, 도마뱀, 사막여우, 오리, 꼬꼬닭, 금붕어, 카멜레온, 우파루파, 사슴벌레, 병아리, 슈가글라이더, 다람쥐, 사슴, 펭귄, 곰돌이, 유니콘, 너구리
                
            - 숫자
                
                001~999
                
            - 조합예시
                
                `졸린고양이17`, `포근한강아지329, 말랑한햄스터51`
                
        - 기본 닉네임을 유저가 변경하지 않을 경우 해당 조합의 닉네임은 재활용되지 않음 - 닉네임 가능 조합에서 삭제 (개발 후순위)
        - 기본 닉네임 부분을 터치하여, 새로운 닉네임 변경 가능
