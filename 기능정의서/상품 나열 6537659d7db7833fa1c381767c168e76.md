# 상품 나열

기능 짧은 desciption: 좋아요 화면
기능그룹: 좋아요
상위 항목: 메인 네비게이션 내 좋아요 화면 (%EB%A9%94%EC%9D%B8%20%EB%84%A4%EB%B9%84%EA%B2%8C%EC%9D%B4%EC%85%98%20%EB%82%B4%20%EC%A2%8B%EC%95%84%EC%9A%94%20%ED%99%94%EB%A9%B4%208777659d7db7825298fe8169baa0dcb1.md)
세부 그룹: 상품 나열
우선순위/논의 사항: 보통(3순위)

- 유저가 ‘좋아요’ 누른 상품 데이터 (상품 카드) 나열
- 기본 - 좋아요 누른 최신순 나열
- 좋아요 내 상품 정렬 (개발 후순위)
- 상품 카드 클릭 시 상품 상세 페이지로 이동
- 상품 카드 내 ‘좋아요’ 버튼 클릭 시 좋아요 리스트에서 해당 상품 삭제
- 상품 카테고리 (사료, 간식, 영양제) 태그만 존재
- 최근에 봤어요, 자주 샀어요 → UI목업(클릭 비활성화)
