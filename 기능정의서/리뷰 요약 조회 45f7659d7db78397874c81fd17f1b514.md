# 리뷰 요약 조회

- 상품 리뷰 영역 상단에 리뷰 요약 정보 제공
- AI 리뷰 요약 제공 시 전체 리뷰 내용을 기반으로 주요 의견을 요약하여 노출
- 등록된 리뷰가 없는 경우 리뷰 없음 상태 제공
- Ai 리뷰 요약은 최소 5개 이상의 리뷰가 등록된 경우에만 제공
- AI 리뷰 요약에 대한 피드백 - 도움이 됐어요/ 도움이 안 됐어요 버튼 (아이콘형태)
    - 각 피드백을 누르면, 해당 피드백이 Ai 리뷰 데이터에 반영 (개발 후순위)
