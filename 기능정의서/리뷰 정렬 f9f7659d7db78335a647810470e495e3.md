# 리뷰 정렬

기능 짧은 desciption: 추천순(리뷰 ‘좋아요’ 버튼이 눌린 순), 최신순, 별점높은순, 별점 낮은 순
기능그룹: 리뷰
상위 항목: 리뷰 탭 | 리뷰 페이지 (%EB%A6%AC%EB%B7%B0%20%ED%83%AD%20%EB%A6%AC%EB%B7%B0%20%ED%8E%98%EC%9D%B4%EC%A7%80%208ba7659d7db7838da27481497c72c3db.md)
세부 그룹: 리뷰 목록
우선순위/논의 사항: 보통(3순위)

- 리뷰 목록 상단에 현재 적용된 정렬 기준 표시
- 정렬 버튼 선택 시 정렬 옵션 제공
- 추천순 / 최신순 / 별점 높은순 / 별점 낮은순 제공
    - 추천순: 리뷰 좋아요를 받은 순
- 최초 진입 시 추천순을 기본값으로 적용
- 정렬 기준 선택 즉시 현재 필터 조건을 유지한 상태에서 리뷰 목록 재정렬
- 선택한 정렬 기준을 화면에 표시
