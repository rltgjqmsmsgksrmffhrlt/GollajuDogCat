# 비교 상품 조회

기능 짧은 desciption: 상품 비교
기능그룹: 상품 비교
상위 항목: 메인 네비게이션 내 상품 비교 (%EB%A9%94%EC%9D%B8%20%EB%84%A4%EB%B9%84%EA%B2%8C%EC%9D%B4%EC%85%98%20%EB%82%B4%20%EC%83%81%ED%92%88%20%EB%B9%84%EA%B5%90%20bd17659d7db783bcbf1f81e82ed6ba42.md)
세부 그룹: 비교 상품
우선순위/논의 사항: 높음(2순위)

![image.png](image%2010.png)

- 상품 상세 또는 추천 상품 화면에서 `다른 상품과 비교`를 통해 추가한 상품을 비교 화면에 노출한다.
- 비교 가능한 상품은 최대 2개로 제한한다.
- 각 비교 상품별 `대표 이미지, 상품명, 가격`을 기본 정보로 제공한다.
    - **최종 점수 = AI에서 전달하는 적합도**
    - 이때 해당 프로필에 치명적인 성분이 있는 경우
        - **해당 성분 태그는 빨간색+볼드체**
- 비교 상품의 상세정보는 동일한 비교 항목 기준으로 정렬하여 제공한다.
- 비교 상품 대표 이미지 선택 시 해당 상품의 상세 화면으로 이동할 수 있다.
- 비교 상품이 1개만 존재하는 경우 추가 상품 선택 영역을 제공한다.
    - 빈 슬롯의 경우 ‘상품 추가하기’ 버튼 노출
        - `‘비교 상품 추가’` 명세 참고
- 장바구니 담기 버튼 클릭 시
    - 장바구니 추가 완료 후 완료 안내 제공 (’장바구니에 상품을 넣었어요!’ 토스트 메세지 3초 노출)
