# 검색 결과 정렬

기능그룹: 검색
상위 항목: 검색 페이지 (%EA%B2%80%EC%83%89%20%ED%8E%98%EC%9D%B4%EC%A7%80%202867659d7db782c9a29881c3101fdd93.md)
세부 그룹: 검색 결과 정렬
우선순위/논의 사항: 높음(2순위)

정렬 기준 (개발 사항에 따라 변경 가능)

<aside>

- 추천순
    - 선택된 반려동물 프로필 정보와 상품의 적합도를 기반으로 산출된 추천 우선순위 기준
- 인기순
    - 일정 기간 판매량이 높은 순으로 정려
- 낮은 가격순
    - 실제 판매 가격 기준 오름차순
- 높은 가격순
    - 실제 판매 가격 기준 내림차순
- 리뷰 많은 순
    - 등록된 유효한 리뷰 수 기준 내림차순
</aside>

- 최초 진입 시 추천순을 기본값으로 적용
- 정렬 버튼 선택 시 정렬 옵션 Bottom Sheet 또는 Dropdown 노출
- 정렬 기준 선택 즉시 결과 목록 갱신
- 현재 적용된 정렬 기준을 화면에 표시
- 동일 검색 세션 내에서는 선택한 정렬 기준 유지
