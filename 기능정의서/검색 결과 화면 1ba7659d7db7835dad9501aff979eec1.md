# 검색 결과 화면

기능그룹: 검색
상위 항목: 검색 페이지 (%EA%B2%80%EC%83%89%20%ED%8E%98%EC%9D%B4%EC%A7%80%202867659d7db782c9a29881c3101fdd93.md)
세부 그룹: 검색 결과 조회
우선순위/논의 사항: 높음(2순위)

- 검색 결과 화면 상단에 검색어 노출
- 검색어에 해당하는 상품 목록 조회
- 검색된 상품 총 개수 표시 (ex, 총 24개)
- 검색 결과 정렬 (자세한 사항은 ‘검색 결과 정렬’ 페이지에서 확인 가능)
- 상품 카드 단위로 검색 결과 노출
- 상품 카드 정보
    
    <aside>
    
    · 대표 이미지
    · 브랜드명
    · 상품명
    · 판매 가격
    
    · 100g 또는 100ml 당 가격
    · 할인율
    · 할인 적용 가격
    · 별점
    · 리뷰 수
    · **반려동물 적합도** 
    
    </aside>
    
- 상품 선택 시 상품 상세 화면으로 이동
- 검색 결과가 없는 경우 Empty 화면 노출
    - “검색 결과가 없습니다”
- Empty 화면에서 검색어 수정/재검색 가능
