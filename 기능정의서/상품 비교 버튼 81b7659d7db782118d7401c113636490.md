# 상품 비교 버튼

기능 짧은 desciption: 상품 비교 페이지로 이동
기능그룹: 상품 상세
상위 항목: 상품 상세 페이지 (공통) (%EC%83%81%ED%92%88%20%EC%83%81%EC%84%B8%20%ED%8E%98%EC%9D%B4%EC%A7%80%20(%EA%B3%B5%ED%86%B5)%204b37659d7db783f38a0981f400cd85ba.md)
세부 그룹: 상품 비교
우선순위/논의 사항: 높음(2순위)

- 상품 상세 페이지 내에서 상품 비교하기 버튼을 누르면
    - 상품이 비교화면에 추가되었습니다! (스낵바)
    - 스낵바 내 버튼= ‘비교화면으로 이동’ or ‘바로가기’ (편한 UX 사용해주셔도 상관없음)
    
    ---
    
    `‘자세한 부분 상품 비교 명세 참고’`
    
- 비교하기 화면 내 상품이 한 개만있을 경우
    - 글로벌 네비게이션 내 ‘상품 비교’ 에 표시 (아이콘 상단 점-색은 기본색(브랜드색))
- 비교하기 화면 내 상품이 두 개 모두 채워진 경우 (쿠키형태, 사용자가 어플 내 있는 경우엔 저장)
    - ‘비교하기 화면으로 이동’ or ‘상품이 모두 채워졌어요! 확인해볼까요?’ 등 안내 문구
