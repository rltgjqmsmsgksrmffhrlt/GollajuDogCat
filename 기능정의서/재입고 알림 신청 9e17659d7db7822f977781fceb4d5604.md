# 재입고 알림 신청

기능 짧은 desciption: 품절일 경우 장바구니/바로 구매 버튼 → 재입고 알림 신청 버튼
기능그룹: 상품 상세
상위 항목: 상품 상세 페이지 (공통) (%EC%83%81%ED%92%88%20%EC%83%81%EC%84%B8%20%ED%8E%98%EC%9D%B4%EC%A7%80%20(%EA%B3%B5%ED%86%B5)%204b37659d7db783f38a0981f400cd85ba.md)
세부 그룹: 재입고
우선순위/논의 사항: 낮음(4순위)

- 상품이 품절된 경우 `장바구니` 및 `바로 구매` 버튼 대신 `재입고 알림` 버튼 제공
- 재입고 알림 버튼 선택 시 해당 상품의 재입고 알림 신청
- 이미 신청한 상품인 경우 신청 완료 상태 표시
- 재입고 발생 시 사용자에게 알림 제공
- 재입고 알림 취소 기능 제공 여부는 정책에 따라 적용
