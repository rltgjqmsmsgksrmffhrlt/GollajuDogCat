1. 아이를 소개해주세요
    - **반려동물 사진(선택)**
        - 없다면-기본이미지 (반려동물 이름 앞 두글자 + 랜덤 색깔(기본이미지 명세 참조))
    - 반려동물 이름(필수)
    - 성별(필수)
    - 중성화 여부(필수)
2. [반려동물이름]에 대해 더 알려주세요
    - 반려동물 종 (검색화면)
    - 나이(필수)
    - 생일(선택)
    - 체구(필수)
    - 몸무게(필수)
    - 체형(필수)
        - 매우 마름 - 마름 - 보통 -통통 -비만
        - bcs→소개 바텀시트
3. 꼼꼼하게 건강을 챙겨줄게요
    - 평소 신경 쓰이는 곳 (선택)
        - 클릭 시 ‘걱정되는 질환’ 필터 형식으로 바텀시트
            - 관절
            - 알러지
            - 체중
            - 장 건강
            - 구강 관리
            - 노화
    - 피해야 할 알러지 성분
4. 프로필 추가 완료
    - 홈으로 이동
    - 맞춤 사료 보러가기
    - 토스트 모달 내 프로필 추가 버튼
        - "또 다른 아이가 있나요? 프로필 추가가 가능해요!"
        - 있어요 → 프로필 추가 작성 (아까와 같은 형식으로 이동)
        - 없어요 → “프로필이 등록되었습니다! 우리 아이를 위한 상품을 함께 찾아보아요!” 모달 | 토스트 메시지 이후 3초 뒤 메인 화면으로 진입
