# 장바구니 담기

기능 짧은 desciption: 비교 화면 내 선택한 상품 장바구니에 추가
기능그룹: 상품 비교
상위 항목: 메인 네비게이션 내 상품 비교 (%EB%A9%94%EC%9D%B8%20%EB%84%A4%EB%B9%84%EA%B2%8C%EC%9D%B4%EC%85%98%20%EB%82%B4%20%EC%83%81%ED%92%88%20%EB%B9%84%EA%B5%90%20bd17659d7db783bcbf1f81e82ed6ba42.md)
세부 그룹: 구매
우선순위/논의 사항: 높음(2순위)

- 각 비교 상품별 `장바구니` 버튼을 제공한다.
- 버튼 선택 시 해당 상품을 장바구니에 추가한다.
- 필수 옵션이 존재하는 경우 옵션 선택 후 장바구니 추가가 가능하다.
    - 옵션 선택의 경우 바텀 시트로 옵션 선택 가능
- 장바구니 추가 완료 시 완료 안내 메시지를 제공한다.
    - 장바구니 추가 완료 후 완료 안내 제공 (’장바구니에 상품을 넣었어요!’ 토스트 메세지 3초 노출)
- 품절 상품은 장바구니 버튼을 비활성화하거나 재입고 알림 기능으로 대체한다.
