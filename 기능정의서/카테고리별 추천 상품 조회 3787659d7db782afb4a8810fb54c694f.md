# 카테고리별 추천 상품 조회

기능 짧은 desciption: 각 상품 카테고리별 추천 상품 제공
기능그룹: 상품 추천
상위 항목: 상품 추천 페이지  (%EC%83%81%ED%92%88%20%EC%B6%94%EC%B2%9C%20%ED%8E%98%EC%9D%B4%EC%A7%80%207eb7659d7db7827c8ec80149fc558d78.md)
세부 그룹: 추천 상품
우선순위/논의 사항: 높음(2순위)

![image.png](image%209.png)

- 추천 상품은 -사료, 간식, 영양제- 카테고리별로 구분하여 제공한다.
- 각 카테고리별로 선택된 반려동물에 대한 적합도가 높은 상품을 우선 노출한다.
    - AI 추천 기준)
- 카테고리별 추천 상품이 없는 경우 해당 카테고리 Empty 상태를 제공
- 카테고리 전환 시 해당 카테고리의 추천 상품 목록을 조회한다.
