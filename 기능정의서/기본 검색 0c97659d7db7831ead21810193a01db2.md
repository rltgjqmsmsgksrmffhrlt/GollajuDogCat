# 기본 검색

Function ID: FUNC-003-01
기능 짧은 desciption: 검색창에 검색어를 입력 한 후 ‘검색 버튼’ 또는 키보드 내 ‘엔터’ 클릭 시, 해당 검색어 기준으로 상품 검색 수행
기능그룹: 검색
상위 항목: 검색 페이지 (%EA%B2%80%EC%83%89%20%ED%8E%98%EC%9D%B4%EC%A7%80%202867659d7db782c9a29881c3101fdd93.md)
세부 그룹: 상품 검색
우선순위/논의 사항: 높음(2순위)
확인필요: BE 확인필요

![image.png](image%202.png)

메인 페이지 내에서 검색 아이콘 선택 시 이동하게 되는 화면

- 상단 ‘<’ 버튼 클릭 시 메인 화면으로 이동
- 상품명, 브랜드명, 카테고리명을 기준으로 검색어 입력 가능
- 검색어 입력 필드에 자동 포커스
- OS 키보드 노출
- 상품명 / 브랜드명 / 카테고리명 등을 기준으로 검색
- 검색어 입력 후 검색 버튼 또는 키보드 Enter/Search 선택 시 검색 실행→ 현재 와이어프레임에는 ‘취소’ 버튼만 있습니당

- 자동 완성(후순위) - 논의 필요
    
    ![스크린샷 2026-09-01 오후 3.36.01.png](%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-09-01_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_3.36.01.png)
    
- 검색어 앞뒤 공백 제거 후 검색
- 입력값이 없는 상태에서는 검색 실행 불가
    - ‘검색어를 입력해주세요!’ 토스트 메세지 (후순위 개발)
- placeholder: ‘상품을 검색해보세요’
- 검색 실행 시( 검색 결과 화면으로 이동
- 검색 결과 화면 상단에 입력한 검색어 유지
- 검색 바 내 ‘X’ 클릭 시 입력된 검색어가 모두 사라짐
