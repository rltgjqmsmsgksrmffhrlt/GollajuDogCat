# 비교 분석 요약

기능 짧은 desciption: 비교 상품의 주요 차이점과 장단점을 Ai 기반으로 요약 제공
기능그룹: 상품 비교
상위 항목: 메인 네비게이션 내 상품 비교 (%EB%A9%94%EC%9D%B8%20%EB%84%A4%EB%B9%84%EA%B2%8C%EC%9D%B4%EC%85%98%20%EB%82%B4%20%EC%83%81%ED%92%88%20%EB%B9%84%EA%B5%90%20bd17659d7db783bcbf1f81e82ed6ba42.md)
세부 그룹: AI 분석
우선순위/논의 사항: 보통(3순위)

- 비교 상품의 상품 정보, 영양성분 및 주요 성분 차이를 기반으로 AI 비교 요약을 제공한다.
- 상품별 주요 장점 및 차이점을 간결하게 제공한다.
- 객관적인 상품 정보를 기반으로 분석하며 확인되지 않은 효능을 단정적으로 표현하지 않는다.
- 비교 가능한 정보가 부족한 경우 분석 결과 대신 정보 부족 안내를 제공한다.
- **프로필 내 꼭 확인해야 할 ‘주의성분’ 등이 있는 경우 AI 분석 요약에서 다시 한 번 강조한다**
