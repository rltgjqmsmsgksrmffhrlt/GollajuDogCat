# 바로 구매

기능 짧은 desciption: 비교 화면 내 선택한 상품 기준으로 구매 절차로 이동
기능그룹: 상품 비교
상위 항목: 메인 네비게이션 내 상품 비교 (%EB%A9%94%EC%9D%B8%20%EB%84%A4%EB%B9%84%EA%B2%8C%EC%9D%B4%EC%85%98%20%EB%82%B4%20%EC%83%81%ED%92%88%20%EB%B9%84%EA%B5%90%20bd17659d7db783bcbf1f81e82ed6ba42.md)
세부 그룹: 구매
우선순위/논의 사항: 보통(3순위)

- 각 비교 상품별 `바로 구매` 버튼을 제공한다.
- 선택 시 해당 상품을 기준으로 주문/결제 화면으로 이동한다.
- 필수 옵션이 있는 상품은 옵션 선택 완료 후 구매 가능하다.
- 품절 상품은 바로 구매 기능을 제공하지 않는다.
