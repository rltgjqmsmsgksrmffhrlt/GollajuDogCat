# 전화번호 입력

기능그룹: 온보딩|회원관리
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%2022e7659d7db783c89e2801344978190e.md)
세부 그룹: 전화번호 입력
우선순위/논의 사항: 매우낮음(5순위)

- 실제 MVP 버전 내에서는 문자가 가지 않고, 그냥 ‘인증’을 누르면 입력되는 형태 (목업 형식)이라고 생각해주시면 됩니다

---

- 전화번호 입력
    - 전화번호 인증
        - 인증 문자 발송
        - 인증 유효 시간 3분
    - 재전송
        - 인증을 누르면 ‘재전송’버튼으로 자동적으로 바뀜
- 약관 동의 체크박스 (필수)
    - 전문 보기 버튼 → 서비스 이용약관으로 이동
- 마케팅 수신 체크 박스 (선택)
    - 전문 보기 버튼 → 마케팅 정보 수신 동의 전문으로 이동
- 확인버튼
    - 회원 가입 완료 후 ‘**온보딩 화면-반려동물 등록 화면**’으로 이동
    - 전화번호 인증 이후 확인 버튼 활성화 (이전에는 비활성화)
