[ 추천 상품 상세 페이지 내 ]

- `다른 상품과 비교` 버튼 선택 시 현재 상품을 비교 목록에 추가
    - 추가와 동시에 ‘상품 비교’ 페이지로 이동

- 비교 목록에 이미 포함된 상품은 중복 추가하지 않음
- 비교 가능한 최대 상품 수 초과 시 안내 메시지 노출 (최대 2개)
- 비교 상품 추가 완료 후 비교 화면으로 이동하거나 비교 목록 진입 CTA 제공
