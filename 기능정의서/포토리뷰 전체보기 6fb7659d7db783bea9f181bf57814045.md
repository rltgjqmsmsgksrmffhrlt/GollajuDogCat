# 포토리뷰 전체보기

기능 짧은 desciption: 대표 포토 리뷰 섹션 내 ‘전체보기’ 버튼 클릭 시 포토 리뷰 목록 화면으로 이동
기능그룹: 리뷰
상위 항목: 리뷰 탭 | 리뷰 페이지 (%EB%A6%AC%EB%B7%B0%20%ED%83%AD%20%EB%A6%AC%EB%B7%B0%20%ED%8E%98%EC%9D%B4%EC%A7%80%208ba7659d7db7838da27481497c72c3db.md)
세부 그룹: 포토 리뷰
우선순위/논의 사항: 보통(3순위)

![image.png](image%2016.png)

- 대표 포토 리뷰 영역의 `전체보기` 선택 시 해당 상품의 전체 포토 리뷰 목록 화면으로 이동
- 상단 포토 리뷰 갯수 표시
- 포토 리뷰 이미지를 목록 형태로 제공 (가로 3개, 각 리뷰의 대표 이미지)
- 이미지 선택 시 해당 이미지가 포함된 리뷰 상세 내용을 조회
