# 리뷰 필터 초기화

기능 짧은 desciption: 리뷰 필터 조건 전체 해제, 전체 리뷰 목록으로 초기화
기능그룹: 리뷰
상위 항목: 리뷰 필터 부분 (%EB%A6%AC%EB%B7%B0%20%ED%95%84%ED%84%B0%20%EB%B6%80%EB%B6%84%206c57659d7db783c4baa3012b5c8cc915.md)
세부 그룹: 리뷰 목록
우선순위/논의 사항: 높음(2순위)

- 적용된 리뷰 필터의 `초기화` 선택 시 사용자가 선택한 모든 필터 조건 해제
    - 바텀 시트 내 초기화
    - 리뷰
- 맞춤 리뷰 조건 및 직접 선택한 기본 필터의 초기화 범위는 정책에 따라 적용
- 초기화 완료 후 전체 리뷰 목록을 기본 상태로 제공
- 정렬 조건은 필터 초기화 대상에서 제외하고 현재 선택값 유지
