# 리뷰 조회

기능 짧은 desciption: 상품 상페 페이지 내에서의 리뷰 조회 → ‘리뷰’ 카테고리 확인 (리뷰 탭)
기능그룹: 상품 상세
상위 항목: 상품 상세 페이지 (공통) (%EC%83%81%ED%92%88%20%EC%83%81%EC%84%B8%20%ED%8E%98%EC%9D%B4%EC%A7%80%20(%EA%B3%B5%ED%86%B5)%204b37659d7db783f38a0981f400cd85ba.md)
세부 그룹: 리뷰 TAB
우선순위/논의 사항: 높음(2순위)

![image.png](image%2034.png)

- 상품 상세 페이지 내에서 [ 리뷰 ] 탭을 클릭시 리뷰 조회 가능
- `리뷰` 명세 확인
