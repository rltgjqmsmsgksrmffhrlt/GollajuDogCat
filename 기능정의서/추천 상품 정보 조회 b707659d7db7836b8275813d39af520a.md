# 추천 상품 정보 조회

기능 짧은 desciption: 상품 이미지, 상품명, 가격, 적합도 등 주요 정보 제공
기능그룹: 상품 추천
상위 항목: 상품 추천 페이지  (%EC%83%81%ED%92%88%20%EC%B6%94%EC%B2%9C%20%ED%8E%98%EC%9D%B4%EC%A7%80%207eb7659d7db7827c8ec80149fc558d78.md)
세부 그룹: 추천 상품
우선순위/논의 사항: 높음(2순위)

![image.png](image%2032.png)

**기능 상세**

- 추천 상품 카드에 대표 이미지, 브랜드명, 상품명, 가격, 할인 여부, 평균 별점, 리뷰 수, 적합도 등 주요 정보를 제공한다.
- 추천 상품 카드에는 대표 추천 근거 요약을 함께 제공할 수 있다. (AI요약 건으로 개발 후순위)
- 품절 상품인 경우 품절 상태를 표시한다. (상품 대표 이미지 등에 ‘품절’ 표시)
- 추천 상품 카드 선택 시 해당 상품의 추천 상품 상세 화면으로 이동한다.
    - ‘상품 상세’ 참고 - 일반 상품 상세 화면의 공통 기능 재사용
    - 추천 상품 카드 선택 시 상세 화면으로 넘어가는 경우에 **‘추천 근거 조회’만 추가됨 (개발 후순위)**

**노출 정보 예시**

- 대표 이미지
- 상품명
- 브랜드명
- 정상가 / 판매가 / 할인율
- 별점 / 리뷰 수
- 우리 아이 맞춤 정도 점수
- 추천/주의 요약
