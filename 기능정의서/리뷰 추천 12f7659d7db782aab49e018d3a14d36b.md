# 리뷰 추천

기능 짧은 desciption: 리뷰의 도움이 돼요/추천 버튼 선택 시 사용자 반응을 저장하고 좋아요 수 갱신, 이후 ‘추천순’ 정렬에 반영
기능그룹: 리뷰
상위 항목: 리뷰 탭 | 리뷰 페이지 (%EB%A6%AC%EB%B7%B0%20%ED%83%AD%20%EB%A6%AC%EB%B7%B0%20%ED%8E%98%EC%9D%B4%EC%A7%80%208ba7659d7db7838da27481497c72c3db.md)
세부 그룹: 리뷰 상세
우선순위/논의 사항: 낮음(4순위)

- 리뷰의 추천/도움돼요 버튼 선택 시 해당 리뷰에 대한 사용자 반응 등록
- 해당 아이콘 옆 아이콘 버튼 클릭 한 유저 수 노출
- 로그인 사용자 기준 리뷰당 1회만 등록 가능
- **등록 후 버튼 활성 상태 및 누적 수 갱신**
- **활성화된 버튼 재선택 시 반응 취소 및 누적 수 감소**
- 본인이 작성한 리뷰에 대한 추천은 비활성화 (개발 후순위)
