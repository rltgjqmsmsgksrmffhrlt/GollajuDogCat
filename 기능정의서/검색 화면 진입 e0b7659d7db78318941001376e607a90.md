# 검색 화면 진입

기능 짧은 desciption: 메인 상단 검색 영역 선택 시 검색 화면으로 이동
기능그룹: 메인화면
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%20ed87659d7db78231becb8149a3180ae4.md)
세부 그룹: 검색 영역
우선순위/논의 사항: 높음(2순위)

![image.png](image%2042.png)

- 메인 화면 상단에 검색 아이콘 버튼을 제공한다
- 검색 아이콘 선택 시 검색 화면으로 이동한다.
- 검색 화면 진입 시 검색어 입력 영역에 포커스를 제공한다.
- 실제 검색 기능 및 최근 검색어 정책은 `검색` 기능 명세를 따른다.
