# 상품 목록 조회 (카테고리별)

기능 짧은 desciption: 메인 화면에 상품 목록 조회 | 상단 카테고리를 눌렀을 때 나타나는 뷰
기능그룹: 메인화면
상위 항목: 제목 없음 (%EC%A0%9C%EB%AA%A9%20%EC%97%86%EC%9D%8C%20ed87659d7db78231becb8149a3180ae4.md)
세부 그룹: 카테고리별 화면
우선순위/논의 사항: 높음(2순위)

![image.png](image%2035.png)

- **메인 화면 내 ‘사료’, ‘간식’, ‘영양제’ 탭을 각각 눌렀을 때 나타나는 뷰**
- 메인 화면에 서비스 기준에 따라 선정된 상품 목록을 제공한다.
- 각 카테고리 필터에 맞는 상품 컴포넌트(이하: 상품 카드로 통일)를 나열한다.
- 상품 정렬 드롭다운
    - 추천순 (AI 추천 로직에 따름) - 기본
    - 인기순 (판매순)
    - 리뷰 많은 순
    - 가격 높은 순
    - 가격 낮은 순
- 상품 카드
    
    <aside>
    
    - 상품 대표 이미지
        - 좋아요 버튼
        - 상품 적합도
    - 상품명
    - 할인률
    - 가격
    - 100ml, 100g 당 가격
    - 별점
    - 후기 갯수
    </aside>
    
- 상품 카드 내 ‘좋아요’ 버튼 클릭 시 “`좋아요`” 화면으로 이동
    - `좋아요` 명세 참고
- 상품 카드 클릭 시 해당 상품의 상세 페이지로 이동
    - “`상품 상세`” 명세 참고
