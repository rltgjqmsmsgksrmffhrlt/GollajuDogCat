# 상품 기본 정보 조회 (상단)

기능 짧은 desciption: 상품 상세 상단 대표 이미지, 상품명, 가격(판매가), 할인 정보(할인율), 별점, 리뷰 수 주요 정보 제공
기능그룹: 상품 상세
상위 항목: 상품 상세 페이지 (공통) (%EC%83%81%ED%92%88%20%EC%83%81%EC%84%B8%20%ED%8E%98%EC%9D%B4%EC%A7%80%20(%EA%B3%B5%ED%86%B5)%204b37659d7db783f38a0981f400cd85ba.md)
세부 그룹: 상품 기본 정보
우선순위/논의 사항: 매우높음(1순위)

![image.png](image%2036.png)

- 상품 상세 화면 진입 시 선택한 상품의 기본 정보 조회 (상단에 나타나는 기본 정보 입니다.)
- 상품 상세 화면 상단의 주요 기본정보를 제공한다
- 제공되는 정보
    
    <aside>
    
    - 대표 이미지 (캐러셀) - 첫 이미지는 상품 상세 들어오기 전 ‘기본 이미지’
    - 상품명
    - 정상가 및 판매가
    - 할인 상품인 경우 할인율 및 할인 적용 가격
    - 상품 평균 별점 및 리뷰 수
    </aside>
    
- 상품 이미지가 복수인 경우 이미지 슬라이드 제공
- 품절 상품인 경우 품절 상태 표시
- 상품 상태 및 진입 경로에 따라 추가 정보를 조건부 노출
