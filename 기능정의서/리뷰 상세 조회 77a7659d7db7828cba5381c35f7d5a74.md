# 리뷰 상세 조회

기능 짧은 desciption: 작성자 정보, 작성자 반려 동물 정보, 별점, 작성일, 상품 사용기간 만족도, 재구매 횟수, 리뷰 내용(기본 100자)
기능그룹: 리뷰
상위 항목: 리뷰 탭 | 리뷰 페이지 (%EB%A6%AC%EB%B7%B0%20%ED%83%AD%20%EB%A6%AC%EB%B7%B0%20%ED%8E%98%EC%9D%B4%EC%A7%80%208ba7659d7db7838da27481497c72c3db.md)
세부 그룹: 리뷰 상세
우선순위/논의 사항: 매우높음(1순위)

- 리뷰 작성자의 ~~프로필 이미지 및~~ 닉네임 제공
- 리뷰 이미지가 존재하는 경우 첨부 이미지 제공
    - 기본 3장 (최대 입력값 - MVP 버전 내는 3장이 기본)
- 리뷰 작성일 제공
- 작성자의 반려동물 기본 프로필 제공
· 반려동물 이름 또는 표시명
· 종/품종
· 나이
· 체중 | 체형 등 bcs 정보
· 성별 및 중성화 여부
· 건강 관심정보 (알레르기, 주의해야 할 건강 특징 최대 5개 나열 - (더보기) 클릭 시 전체 나열)
- 상품 별점 제공
    - 별 채워지는 건 ‘내림’으로 4.5 → 4개 채워짐
    - 첫번째 소수점까지 표시
- 옵션이 있는 상품의 경우 옵션 노출 (없는 경우 미노출)
- 상품 사용 기간 제공
    - 구매 확정부터 사용을 시작했다고 가정
- 만족도 정보 제공
    - 아주 좋아요 | 좋아요 | 보통이에요 | 별로에요 | 아주 별로에요
- 재구매 횟수 제공
- 작성된 리뷰 본문 제공
    - 100글자까지 기본 노출
    - [전체보기]를 누르는 경우 전체 리뷰 text 제공
- 사용자 본인이 작성한 리뷰인 경우 별도의 수정/삭제 기능 제공 여부는 정책에 따라 적용 ( 개발 후 순위)
- 리뷰 신고하기 (개발 후 순위)
    - `리뷰 상세_리뷰 신고` 명세 참고
- 리뷰 추천 (개발 후 순위)
    - `리뷰 상세_리뷰 추천` 명세 참고
- 리뷰 상세 페이지 내 스와이프 시 다른 리뷰 상세 페이지로 이동
