# 비교 상품 변경

기능 짧은 desciption: 비교 중인 상품을 제거하거나 다른 상품으로 변경
기능그룹: 상품 비교
상위 항목: 메인 네비게이션 내 상품 비교 (%EB%A9%94%EC%9D%B8%20%EB%84%A4%EB%B9%84%EA%B2%8C%EC%9D%B4%EC%85%98%20%EB%82%B4%20%EC%83%81%ED%92%88%20%EB%B9%84%EA%B5%90%20bd17659d7db783bcbf1f81e82ed6ba42.md)
세부 그룹: 비교 상품
우선순위/논의 사항: 보통(3순위)

- 상품 비교 상단 ‘x’ 버튼 클릭 시, 해당 부분 empty view로 설정
    - ‘해당 상품이 비교에서 제외되었습니다.’ 안내 문구(토스트 메세지-3초)
- empty view 내 ‘변경된 부분’ 슬롯으로 새로운 비교 상품이 나타남
