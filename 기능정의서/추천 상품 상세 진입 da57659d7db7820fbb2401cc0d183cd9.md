# 추천 상품 상세 진입

기능 짧은 desciption: 추천 상품 상세 정보 조회 - 상품 상세 참고
기능그룹: 상품 추천
상위 항목: 상품 추천 페이지  (%EC%83%81%ED%92%88%20%EC%B6%94%EC%B2%9C%20%ED%8E%98%EC%9D%B4%EC%A7%80%207eb7659d7db7827c8ec80149fc558d78.md)
세부 그룹: 추천 상품
우선순위/논의 사항: 매우높음(1순위)

- ‘상품 추천’ 섹션에서 추천 상품의 대표 사진이나 상품 description(상품명, 가격 등) 을 클릭할 시 상품 상세 페이지로 진입
- 상품 추천에서 ‘상품 상세’로 이동한 경우, 상단 ‘추천 근거 조회’ 추가 (개발 후순위)
