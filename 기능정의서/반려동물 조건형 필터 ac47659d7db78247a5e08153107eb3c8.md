# 반려동물 조건형 필터

기능 짧은 desciption: 종, 나이, 체중, 중성화여부, 건강 관심사 등 조건을 선택하여 리뷰를 필터링
기능그룹: 리뷰
상위 항목: 리뷰 필터 부분 (%EB%A6%AC%EB%B7%B0%20%ED%95%84%ED%84%B0%20%EB%B6%80%EB%B6%84%206c57659d7db783c4baa3012b5c8cc915.md)
세부 그룹: 반려동물리뷰 필터
우선순위/논의 사항: 보통(3순위)
확인필요: PD확인필요

- 기본 리뷰 필터 선택 시 필터 조건 선택 `Bottom Sheet` 제공 (무신사 참고)
- 종, 품종, 나이, 체중, 중성화 여부, 건강 관심사 등의 필터 항목 제공
- 각 필터 리뷰 AND 조건 (교집합)
- 각 항목별 복수 조건 선택 가능
- 필터 조건 적용 시( 필터 확인 버튼을 누를 경우) 선택한 조건에 해당하는 리뷰 목록으로 갱신
- 적용된 조건은 리뷰 화면 상단에 태그 또는 선택된 상태로 표시
- 선택한 조건이 없는 경우 전체 리뷰 제공
