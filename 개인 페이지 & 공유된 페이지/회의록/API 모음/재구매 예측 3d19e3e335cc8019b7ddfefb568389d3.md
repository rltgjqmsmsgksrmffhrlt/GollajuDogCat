# 재구매 예측

## 1. 엔드포인트 목록

| 엔드포인트 | Method | 용도 |
| --- | --- | --- |
| `/internal/v1/repurchase/recalculations` | POST | 결제·취소·반품·환불 발생 후 예측 재계산 요청 |
| `/internal/v1/repurchase/predictions` | GET | 사용자 또는 반려동물의 최신 구매 시점 예측 조회 |

## 2. 재계산 요청

```json
{
  "event_id": "evt_01JABC123",
  "event_type": "PAYMENT_COMPLETED",
  "occurred_at": "2026-09-03T15:30:00+09:00",
  "user_id": "user_123",
  "order_id": "order_456",
  "affected_order_item_ids": ["order_item_789"]
}
```

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| `event_id` | 필수 | 중복 처리를 방지하는 이벤트 ID |
| `event_type` | 필수 | `PAYMENT_COMPLETED`, `ORDER_CANCELLED`, `ITEM_CANCELLED`, `ITEM_RETURNED`, `ORDER_REFUNDED` |
| `occurred_at` | 필수 | 이벤트 발생 시각. 타임존을 포함한 ISO 8601 형식 |
| `user_id` | 필수 | 예측을 다시 계산할 사용자 |
| `order_id` | 필수 | 상태가 변경된 주문 |
| `affected_order_item_ids` | 선택 | 변경 영향을 받은 주문 상품 ID 배열 |

정상 접수 시 `HTTP 202 Accepted`와 `job_id`를 반환합니다. 동일한 `event_id`가 다시 들어오면 중복 작업을 생성하지 않습니다.

## 3. 예측 결과 조회

```
GET /internal/v1/repurchase/predictions?user_id={user_id}&pet_id={pet_id}
```

- `user_id`: 필수
- `pet_id`: 선택. 없으면 해당 사용자의 전체 결과 조회

## 4. 처리 상태

| 상태 | 의미 |
| --- | --- |
| `READY` | 정상 예측 완료 |
| `COLD_START` | 개인 이력이 부족해 상품군·카테고리 기준 사용 |
| `LOW_CONFIDENCE` | 예측은 생성됐지만 신뢰도가 낮음 |
| `INSUFFICIENT_DATA` | 필수 데이터 부족으로 예측 생성 불가 |
| `PROCESSING` | 최신 구매 정보를 반영해 재계산 중 |
| `SERVICE_DEGRADED` | 이전 정상 결과 또는 fallback 사용 |
| `FAILED` | 예측 작업 실패 |

`COLD_START`, `LOW_CONFIDENCE`, `INSUFFICIENT_DATA`는 시스템 오류가 아니므로 HTTP 200으로 반환합니다.

## 5. 에러 응답

| 상태코드 | 상황 |
| --- | --- |
| 400 | 필수 필드 누락 또는 형식 오류 |
| 401/403 | 내부 서비스 인증 또는 권한 오류 |
| 409 | 이벤트 중복 또는 스키마 버전 충돌 |
| 422 | 지원하지 않는 이벤트 유형 |
| 500 | AI 서버 내부 오류 |
| 503 | 모델·DB·외부 의존 서비스 사용 불가 |

## 6. 갱신 주기

- 결제·취소·반품·환불 발생 시 대상 사용자를 재계산 목록에 등록
- 비동기 작업에서 영향받은 사용자·반려동물·상품군 예측 갱신
- 일 1회 보정 배치로 누락 이벤트와 전체 결과 점검
- 과거 학습 샘플의 `anchor_at`은 유지하고 현재 제공할 예측만 최신 데이터로 갱신

## 7. 협의 필요 사항

- 실제 배포 base URL과 내부 서비스 인증 방식
- 재계산 요청을 HTTP 호출로 유지할지 메시지 큐로 전환할지
- 배치 실행 시간과 재시도 횟수
- 예측 결과 보존 기간과 최신 결과 조회 기준
- 백엔드 상품 정보와 `representative_product_id` 결합 방식
- API timeout·응답시간 SLA
