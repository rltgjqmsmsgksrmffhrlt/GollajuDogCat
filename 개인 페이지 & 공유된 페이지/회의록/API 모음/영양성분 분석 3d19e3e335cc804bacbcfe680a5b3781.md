# 영양성분 분석

## 1. 엔드포인트 목록

| 엔드포인트 | Method | 용도 |
| --- | --- | --- |
| `/internal/v1/nutrition/analyze` | POST | 반려동물 프로필 기준 상품 1개 영양성분 분석 |
| `/internal/v1/nutrition/diff` | GET | 두 상품의 영양성분 및 기준 비교 |
| `/internal/v1/nutrition/exclusions` | GET | 알레르기·대상 종·생애주기 기준 상품 제외 사유 조회 |

## 2. 공통 요청 파라미터

| 파라미터 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `pet_id` | string (UUID 권고) | O | 분석 대상 반려동물 ID |
| `product_id` | string (UUID 권고) | O | 분석 대상 상품 ID |

| 파라미터 | 타입 | 필수 | 설명 |

| `pet_id` | string (UUID 권고) | O | 비교 기준 반려동물 ID |
| `product_id` | string (UUID 권고) | O | 기준 상품 ID |
| `compare_product_id` | string (UUID 권고) | O | 비교 상품 ID |

| 파라미터 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `pet_id` | string (UUID 권고) | O | 안전성 검증 대상 반려동물 ID |

## 3. 공통 응답 형식

모든 API는 다음 공통 응답 구조를 사용한다.

```json
{
  "request_id": "req_01JABC789",
  "status": "READY",
  "data": {},
  "warnings": []
}
```

### `status`

| 값 | 설명 |
| --- | --- |
| `READY` | 정상 분석 완료 |
| `SAFETY_BLOCKED` | 안전성 기준에 의해 상품이 차단됨 |
| `INSUFFICIENT_DATA` | 판단에 필요한 데이터 부족 |
| `SERVICE_DEGRADED` | 일부 기능 제한 상태 |
| `FAILED` | 분석 처리 실패 |

### API별 `data` 주요 필드

| API | 주요 필드 | 설명 |
| --- | --- | --- |
| `analyze` | `overall_judgment` | 상품의 종합 판단 |
|  | `confidence` | 분석 신뢰도 |
|  | `aafco_match` | 반려동물 생애주기와 상품 AAFCO 기준 적합성 |
|  | `nutrients` | 영양성분별 기준 비교 결과 |
|  | `reference_version` | 분석에 사용한 기준 버전 |
|  | `generated_at` | 분석 결과 생성 시각 |
| `diff` | `nutrients` | 영양성분별 비교 결과 및 차이값 |
|  | `aafco_comparison` | 두 상품의 AAFCO 기준 비교 |
|  | `allergy_check` | 반려동물 기준 알레르기 비교 결과 |
| `exclusions` | `is_excluded` | 상품 제외 여부 |
|  | `exclusion_reasons` | 상품 제외 사유 및 reason code |

### 영양성분별 판정

- `comparison_status`: `IN_RANGE`, `OUT_OF_RANGE`, `UNKNOWN`, `NOT_APPLICABLE`
- `display_grade`: `ADEQUATE`, `DEFICIENT`, `EXCESS`, `UNKNOWN`
- `confidence`: `HIGH`, `MEDIUM`, `LOW`, `INSUFFICIENT_DATA`

### 전체 판단

- `overall_judgment`: `IN_RANGE`, `CAUTION`, `NOT_RECOMMENDED`, `INSUFFICIENT_DATA`

### 주요 제외 사유

- `ALLERGY_CONFLICT`
- `SPECIES_MISMATCH`
- `LIFE_STAGE_MISMATCH`
- `SAFETY_DATA_INSUFFICIENT`

### AAFCO 적합성

`aafco_match` 내부에서 다음 정보를 제공한다.

```json
{
  "aafco_match": {
    "life_stage": "ADULT",
    "product_life_stage": "ADULT_MAINTENANCE",
    "is_match": true,
    "aafco_pass_per_product": {
      "policy": "P0D",
      "policy_status": "CURRENT",
      "value": "UNKNOWN",
      "note": "필수 영양소 데이터 부족으로 적합성 판정 불가"
    }
  }
}
```

- `life_stage`: **반려동물의 생애주기**
- `product_life_stage`: **상품의 AAFCO 매핑 생애주기**
- `is_match`: 반려동물 생애주기와 상품 생애주기의 매핑 규칙상 일치 여부

### `aafco_pass_per_product`

- `policy`: `P0D`, `MIN_1_PASS`
- `policy_status`: `CURRENT`, `LEGACY`, `DEPRECATED`
- `value`: `TRUE`, `FALSE`, `UNKNOWN`
- `note`: 판정 근거 또는 데이터 부족 사유

※ `UNKNOWN`은 안전 또는 적합으로 간주하지 않는다.

### `diff` 차이값

영양성분 비교 시 차이값은 다음 기준으로 계산한다.

```
difference = compare_value - base_value
```

- `base_value` 또는 `compare_value` 중 하나라도 `null`이면 `difference`는 `null`로 처리한다.
- 단위가 다른 경우 사전에 정의된 단위로 정규화한 후 비교한다.

## 4. 에러 응답

| HTTP Status | 상황 |
| --- | --- |
| `400` | 잘못된 요청 파라미터 |
| `401` | 인증 실패 |
| `403` | 접근 권한 없음 |
| `404` | 반려동물 또는 상품 정보 없음 |
| `422` | 요청 데이터 형식 또는 유효성 오류 |
| `500` | 서버 내부 오류 |
| `503` | AI 서비스 또는 외부 의존 서비스 이용 불가 |

※ `SAFETY_BLOCKED`, `INSUFFICIENT_DATA`는 HTTP 오류가 아니라 **HTTP 200 응답 내 `status`로 전달되는 도메인 상태**이다.

## 5. 갱신 주기

- **상품 영양성분 / 원재료 / AAFCO 기준 데이터**
    - 원천 데이터 변경 또는 기준 버전 변경 시 갱신
- **영양성분 분석 결과**
    - 상품 및 반려동물 정보가 변경되지 않은 경우 캐시 활용
    - 상품 정보, 반려동물 알레르기·생애주기 정보 또는 기준 버전 변경 시 캐시 무효화 후 재분석
- **`/internal/v1/nutrition/analyze`**
    - 분석 결과 캐시 우선 사용
    - 관련 데이터 변경 시 캐시 무효화
- **`/internal/v1/nutrition/diff`**
    - 비교 결과 캐시 사용 가능
    - 비교 대상 상품 정보 또는 기준 데이터 변경 시 캐시 무효화
- **`/internal/v1/nutrition/exclusions`**
    - 안전성 판단 API이므로 **캐시 미사용**
    - 장바구니 및 결제 직전 실시간 재검증
- **분석 방식**
    - 영양성분 및 안전성 판단은 **구조화된 데이터와 사전 정의된 룰 기반으로 수행**
    - LLM은 영양성분 수치 및 안전성 판정에 사용하지 않음
    - 필요한 경우 분석 결과를 사용자 친화적인 문장으로 변환하는 설명 계층에 선택적으로 활용
    - LLM 미사용 또는 장애 시에도 정형화된 템플릿으로 설명 제공

## 6. 협의 필요 사항

- **API Base URL 및 인증 방식**
    - BE와 최종 확정
- **캐시 저장 위치 및 TTL**
    - BE 인프라 기준으로 확정
    - 상품·반려동물·기준 데이터 변경 시 관련 캐시 무효화
- **`/internal/v1/nutrition/exclusions` 호출 시점**
    - 상품 상세 조회 시 기본 검증
    - 장바구니 및 결제 직전 재검증
- **`/internal/v1/nutrition/diff` 화면 반영 범위**
    - 비교할 영양소 및 사용자 노출 항목 FE와 협의
- **데이터 변경 이벤트 전달 방식**
    - 상품/반려동물/기준 데이터 변경 시 분석 캐시 무효화를 위한 BE 연동 방식 협의
- **분석 결과의 사용자 노출 방식**
    - `overall_judgment`, 영양소별 `display_grade`, `reason_code` 및 설명 문구의 FE 노출 범위 협의
- **대상 종 및 생애주기 매핑 규칙**
    - `target_species` 및 `LIFE_STAGE_MISMATCH` 처리 기준 BE/AI 간 최종 확정
- **영양성분 기준 단위**
    - Dry Matter Basis(DMB) 적용 및 단위 변환 기준 최종 확정
- **처리 방식**
    - API 동기/비동기 처리 여부 및 응답 시간 기준 BE와 협의
