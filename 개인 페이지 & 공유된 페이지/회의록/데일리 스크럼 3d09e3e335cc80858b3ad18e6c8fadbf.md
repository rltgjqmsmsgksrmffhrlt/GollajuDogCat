## 2. 현황 공유

### 🔸 데일리 스크럼

---

- 와이어프레임 작업은 디자인팀에서 나오는대로 대응하여 작업 진행중
- 디자인 토큰 작업도 슬슬 준비해야함

### 🔸 팀장 스크럼

---

#### PM

- Phase2 공통 과업 부분은 PM 팀이 총괄적으로 진행중 인터페이스쪽 문서 작업만 진행해주시면 됨

#### PD

- 와이어프레임 핸드오프 (Phase2) 오늘 작성해서 내일 전달
- **웹접근성 회의 (12시)**
    - 문서는 APCA, 실 작업은 WCAG 기준으로 진행
    - 대비값 최소 3:1 확인, 텍스트는 4.5:1로 요청
- 디자인 시스템 작업 오늘 진행해서 내일 오전 중으로 완료 예정
    - 조경화님 코드 작업
    - 전지호 Phase2 산출물 작성

#### 백엔드

- API 계약 (Phase2), API 명세서로 대체해서 진행

#### 인프라

- 휴가

#### 사이버 보안

    - 일정 관련해서는 PM 분들과 조율해봐야함
