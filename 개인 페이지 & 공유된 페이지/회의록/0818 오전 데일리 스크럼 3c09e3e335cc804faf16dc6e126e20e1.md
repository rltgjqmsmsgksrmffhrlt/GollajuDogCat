## 2. 문제 상황 공유

---

🔸 **이슈 공유 및 해결 방안 마련:**

- 기능 추가(생성형 AI 세 번째 기능) 관련 팀별 입장
    - 반대: 디자인, PM, BE
    - 반반: FE
    - 특별한 이견 없음: 인프라
    - AI팀은 원래 배정된 기능이라 추가로 보지 않음, 세 기능 모두 유지하는 방향에 착수 가능하다는 입장
- 메인 기능 3개 중 재구매 예측만 다른 기능으로 교체하기로 함. 나머지 두 개는 확정 유지
    - 대체 솔루션의 구체적 방향성은 아직 미정 (AI팀 담당자 부재로 오늘/내일 중 확정 예정)
- 오늘 15시 전체 회의 → 진행 상황 공유, 16시부터 솔루션 논의로 일정 확정 → 전체회의 삭제
- AI 기능 구현 착수 시점 관련 이견
    - BE: 시간 낭비하지 않으려면 오늘 솔루션 확정되는 대로 바로 구현 착수하는 게 낫다는 의견
    - 강사: 설계·기획이 나오기 전에 데이터 스키마 등을 먼저 확정 짓고 구현에 들어가면, 이후 기획이 바뀔 때 다시 갈아엎어야 할 위험이 크다고 지적
    - AI팀: 후보 방향들의 구현 가능성과 레퍼런스 조사까지는 미리 진행 가능하나, 실제 구현은 설계가 나올 때까지 보류하기로 함
    - 최종적으로 AI 구현은 아직 들어가지 않는 것으로 결론 (16시 솔루션 논의 이후 재논의)
- 인프라팀 관련: 여진 부재 상태에서 진행됐던 이전 미팅 내용에 오류가 있어 인프라팀과 미팅을 다시 잡아야 함
- FE-BE GitHub 협업 방식 관련 질문 있었음 — 특정 레퍼런스를 보고 만든 게 아니라 GitHub Organization으로 팀 그룹 생성, 코드 공유를 위한 일반적인 협업 방식이라는 답변으로 정리됨
- WBS 관련
    - 원래 8/12까지였던 항목이 지연된 상태 → 추후 일정 조정 필요
    - AI/솔루션 관련 항목은 원래 계획대로(오늘~내일)라 지연 아님, 우선순위 때문에 오늘로 당겨진 것
    - AI·인프라 팀은 WBS에 자신들 항목이 아직 반영이 안 되어 있어 추가 필요
    - 팀 간 의존 관계(어떤 산출물이 나와야 다음 작업 가능한지)를 회의에서 구두로만 공유하지 말고 문서화하기로 함
- 인터뷰 진행 관련
    - 사전 확보 인원 12명, 응답 수가 많지 않아 정량 통계보다는 문제 간 상대적 우선순위를 파악하는 용도로 활용하기로 함
    - 파일럿 인터뷰 대상자는 경환 우선 고려하다가, 디자인팀은 질문을 미리 알고 있어 부적절하다는 의견에 따라 조율
    - 인터뷰 질문·프로필은 인터뷰 설계서(PMPD 워크스페이스)에서 오늘 중 확정하기로 함, 설문조사 문항과 겹치지 않게 열린 질문 위주로 조정 필요
- 디자인팀 WBS 관련 FE와 협의 결과 현재 기준 수정사항 없음, 추후 지연 발생 시 재논의

## 3. 피드백 및 개선 사항

---

🔸 **피드백:** 팀 내 또는 외부(강사,멘토)에서 받은 피드백을 작성합니다.

- 강사: AI 기능 구현을 설계·기획 확정 전에 먼저 시작하면, 추후 기획 변경 시 백엔드 테이블 구조 등을 다시 갈아엎어야 할 수 있으니 설계를 더 다진 뒤 진행할 것을 권장
- 강사: 완벽하게 다 만들어서 공유하기보다 어느 정도 윤곽이 잡히면 빠르게 공유하는 방식을 권장
- 강사: 회의 중 나온 팀 간 의존 관계(어떤 산출물을 기다려야 하는지)를 구두로만 넘기지 말고 명확히 문서화할 것을 제안
- 팀장: 회의록 작성이 어려우면 음성 인식 도구(예: ALT) 활용을 제안, 특히 의사결정 사항 위주로 기록할 것을 권장

🔸 **개선 사항:** 피드백을 바탕으로 개선할 점을 작성합니다.

- AI 기능 구현은 설계·아키텍처가 확정되기 전까지 보류, 후보안 조사·레퍼런스 조사까지만 우선 진행
- 팀 간 의존/대기 관계는 WBS나 별도 문서에 명시적으로 기록
- 회의 진행 상황과 의사결정을 실시간으로 문서화하는 루틴 강화 (도구 활용 검토)
