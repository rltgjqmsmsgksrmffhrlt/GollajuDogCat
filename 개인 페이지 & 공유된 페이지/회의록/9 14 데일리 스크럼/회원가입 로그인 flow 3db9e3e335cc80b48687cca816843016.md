# 회원가입/로그인 flow

### 사전준비

1. 로컬 인프라 실행: `docker compose -f local-infra/docker-compose.yml up -d`
2. 아래 3개 서비스를 IntelliJ에서 `local` 프로필로 실행 
(실행 설정에 `.env` 파일 연결(`envFilePaths`) 필요)
- Active profiles, Environment variables 각 서비스 별 설정
    
    ![image.png](%ED%9A%8C%EC%9B%90%EA%B0%80%EC%9E%85%20%EB%A1%9C%EA%B7%B8%EC%9D%B8%20flow/image.png)
    
- `api-gateway` (8080)
- `auth-service` (8081)
- `member-service` (8082)
1. `.env` 파일에 필요한 값 (git엔 안 올라가는 값이라 담당자에게 요청)
- JWT_RSA_PRIVATE_KEY 설정
    
    터미널에서 명령어 실행
    
    1. 키 생성
    
    ```jsx
    openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048 -out private_key.pem
    ```
    
    1. 내용 확인
    
    ```jsx
    cat private_key.pem
    ```
    
    ```jsx
    ----BEGIN PRIVATE KEY-----
    MIIEvQIBADANBgkqhkiG9w0BAQEFAASCBKcwggSjAgEAAoIBAQC...
    (여러 줄)
    -----END PRIVATE KEY-----
    
    해당 내용처럼 키 생성됨
    ```
    
    1. env에 붙여넣기
    
    ```jsx
    JWT_RSA_PRIVATE_KEY= 뒤에 따옴표로 감싸서 통째로 붙여넣어요:
    
    JWT_RSA_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----
    MIIEvQIBADANBgkqhkiG9w0BAQEFAASCBKcwggSjAgEAAoIBAQC...
    -----END PRIVATE KEY-----"
    여러 줄 그대로 붙여넣으시면 되고, 앞뒤에 큰따옴표(") 빠뜨리지 않게 주의하세요.
    ```
    
- `services/auth-service/.env`:
    - `KAKAO_CLIENT_ID`,
    - `KAKAO_CLIENT_SECRET`,
    - `GOOGLE_CLIENT_ID`,
    - `GOOGLE_CLIENT_SECRET`,
    - `JWT_RSA_PRIVATE_KEY`, → 개별 설정
    - `INTERNAL_GATEWAY_SECRET`
- member-service, api-gateway .env에도 각각 `INTERNAL_GATEWAY_SECRET` 설정 필요

```jsx
[.env ]
#oauth2
KAKAO_CLIENT_ID=
KAKAO_CLIENT_SECRET=

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET

#JWT
JWT_RSA_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----
...
...
-----END PRIVATE KEY-----"

#gateway-secret
INTERNAL_GATEWAY_SECRET=

```

1. 카카오/구글

구글은 별도 등록 없이 소셜 로그인 가능

카카오는 담당자가 이메일 등록을 해야 함

### 소셜 로그인 → JWT 발급

1. 브라우저 주소창에 입력

```jsx
[카카오]
http://localhost:8080/api/auth/oauth2/authorization/kakao
```

```jsx
[구글]
http://localhost:8080/api/auth/oauth2/authorization/google
```

로그인이 완료되면 아래 형태로 리다이렉트

```jsx
http://localhost:3000/auth/callback?code=xxxxxxxx-xxxx-...
```

1. 주소창의 code값 복사해서 포스트맨 실행

```jsx
[POST] http://localhost:8080/api/v1/auths/token/exchange

[body]
{
    "code" : "a4382090-2a21-46db-ad78-f11bf6cb79e1"
}
```

### 회원가입(첫 소셜로그인만 진행)

```jsx
[POST] http://localhost:8080/api/v1/members/signup

[body] 
{
  "nickname": "순수한슈가글라이더704",
  "agreements": [
    { "type": "AGE_OVER_14", "agreed": true },
    { "type": "SERVICE_TERMS", "agreed": true },
    { "type": "PRIVACY_COLLECTION", "agreed": true },
    { "type": "MARKETING_BENEFIT", "agreed": true },
    { "type": "THIRD_PARTY_PROVIDE", "agreed": true }
  ]
}

[Authorization]
Auth type: Bearer Token
Token: JWT 발급한 accessToken 값
```
