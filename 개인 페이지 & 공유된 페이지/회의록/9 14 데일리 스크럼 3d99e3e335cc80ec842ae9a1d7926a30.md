### **클라우드 전달 사항 (Jenkins CI/CD 파이프라인)**

**PR 올리실 때 (dev 대상)**

PR 열면 자동으로 변경된 서비스만 감지해서 다음이 순서대로 돌아갑니다: 테스트 → 빌드 → Trivy 보안 스캔
이 단계에서는 실제 배포(ECR push 등)는 안 일어납니다. 검증만 합니다.
CRITICAL 등급 보안 취약점이 있으면 스캔에서 막혀서 PR 체크가 실패합니다. 의존성 버전 문제일 가능성이 높으니, 실패하면 어떤 라이브러리 때문인지 로그 확인 부탁드립니다.

**dev에 머지되면**

위 과정(테스트/빌드/스캔)에 이어서 실제로 이미지가 ECR에 push되고, gitops-value 레포가 자동으로 갱신됩니다. ArgoCD가 그 변경을 감지해서 알아서 재배포합니다. 사람이 따로 배포 버튼 누를 필요 없습니다.
여러 서비스가 한 PR에 걸려있으면 순차로 빌드됩니다(서비스 개수만큼 시간 소요).
Jenkins 콘솔 로그로 실패 원인 직접 확인 가능하시고, 접근 방법이나 그 외 궁금한 점 있으시면 언제든 DM 주시면 됩니다. (gitops 레포 task 파일에다가 jenkins id/비번 확인할 수 있는 명령어 넣어두었습니다)
