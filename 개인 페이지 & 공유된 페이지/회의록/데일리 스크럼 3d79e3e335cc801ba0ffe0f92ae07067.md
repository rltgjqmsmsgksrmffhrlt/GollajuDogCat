### 트러블 2 (신동일)

- **발생 문제:** OS 시뮬레이터에서 Burp 인증서 설치 및 신뢰 등록까지 완료하고 HTTPS 사이트([example.com](http://example.com/))에 정상 접속됐으나, Burp Suite의 Proxy → HTTP history에 해당 트래픽이 전혀 기록되지 않음
- **원인:** 작업 도중 Mac이 연결된 Wi-Fi가 변경되면서 Mac의 로컬 IP가 기존 `192.168.219.105`에서 `192.168.219.44`로 바뀌었으나, macOS 시스템 프록시(웹 프록시 HTTP/HTTPS) 설정에는 이전 IP가 그대로 남아있어 시뮬레이터의 트래픽이 존재하지 않는 주소로 전송되어 Burp를 거치지 않은 상태로 처리됨
- **조치 내용:**
- `ifconfig` 명령으로 변경된 현재 IP(`192.168.219.44`) 재확인
- 시스템 설정 → 네트워크 → Wi-Fi → 프록시에서 HTTP/HTTPS 서버 주소를 새 IP로 업데이트
- 시뮬레이터가 변경된 네트워크 설정을 다시 읽도록 `xcrun simctl shutdown all` 후 재부팅
- 재부팅 후 시뮬레이터에서 새 사이트(httpbin.org)로 재접속하여 검증
- **결과:** Burp HTTP history에 `https://httpbin.org`, `https://claude.ai` 등 HTTPS 트래픽이 정상적으로 캡처됨을 확인, Request/Response 내용까지 평문으로 확인 가능 → HTTPS 트래픽 캡처 검증 완료
