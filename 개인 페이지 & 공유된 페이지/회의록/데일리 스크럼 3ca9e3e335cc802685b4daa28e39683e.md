#### 백엔드

- 결제 관련 생각하고 있는 플로우 (토스페이먼츠 확정)
    - 오늘 조사해서 정리하기
- API 명세 검토 관련
    - 파라미터나 body등도 작성이 된 후에 검토 하는게 좋아보인다고 답변드렸음
- 소셜로그인 구현 방식
    - 백엔드가 Spring Security로 리다이렉트까지 처리 → 프론트는 이동/콜백 처리까지만
- 사진 저장 방식
    - 1안: 프론트가 S3 라이브러리를 사용하여 이미지 URL 변환 후, 백엔드 저장 API 요청해서 사진 저장
    - 2안: 백엔드가 S3에 이미지를 올리는 API도 만들어서 관리
        - 이게 좋아보임, 오류 발생 Rollback 처리까지 한 번에 묶어서 관리할 수 있어보임
